# v2.4.7 - 异构 LLM 多智能体协商（Hetero LLM）

## 一句话概述

v2.4.7 引入不同来源/架构的异构 LLM（GPT 系、Claude 系、本地开源等）多智能体协作：独立提案 → 评估评分 → 内部加权投票收敛，并支持跨模型记忆协作。

## 跨智能体协同

- `LlmModel` 登记异构模型（family + 历史可信度权重）。
- `Proposal` 各模型独立提交答案与置信度；未登记模型的提案被拒绝。

## 协商：评估、评分、内部投票

- 评分：`score = 模型历史权重 × 提案置信度`。
- 内部投票：相同答案的提案按 score 累加票数，得票最高者胜出（加权而非简单人头）。

## 跨模型记忆协作

- `CrossModelMemory`：异构模型对同一任务共享经验，标注来源模型与可信度。
- `recall_best()` 按可信度取最佳经验；`distinct_models()` 统计异构独立性。

## 验证

- 加权投票胜出、拒绝未知模型、跨模型记忆最佳检索与独立性计数测试全绿；184 项 cargo 测试通过。

## 边界

- 协商为进程内确定性机制验证（评分/投票收敛），未接真实多家 LLM API；真实接入时模型权重应由独立校准集产生。
