# v2.3.5 - Client（跨平台客户端）+ 三大连接层重构

> 发布日期：2026-09-24
> 代号：Client
> 类型：功能版本（minor）

## 一句话简介

在 v2.3.4 智能体市场之上，新增基于 Tauri 2 的跨平台客户端（macOS / Windows / Android / Linux，iOS 需开发者证书），并重新梳理、重构、补全 CLI、REST API、MCP 三大连接层；守护进程真实 bind P2P/HTTP 端口、SQLite 持久化，三层均可真机走通完整市场闭环。

## 新增功能

### F1 跨平台客户端（Tauri 2）

- 源码：`client/`（前端 Vite + HTML/JS，Rust 壳 `client/src-tauri/`）；`desktop/` 为桌面端源码目录
- 覆盖：macOS（.dmg/.app）、Windows（.msi）、Linux（.deb/.AppImage）、Android（APK，工程已在 `client/src-tauri/gen/android`）
- iOS：需 Apple Developer 证书与描述文件，见 `client/ios/README.md`，开源仓库不内置签名成品
- 界面：显示 SDK 版本、平台、DID，一键运行「充值→质押→发布→投标→匹配→完成→结算→守恒」市场端到端演示
- 安装包为构建产物，不直接入库：由 `.github/workflows/client-build.yml` 在打 tag 时于对应系统 runner 上自动构建并发布到 GitHub Release

### F2 CLI（命令行接口）

- 新增独立子命令式二进制 `gsn`：`version` / `identity` / `daemon` / `mcp` / `market`
- `market` 子命令经 HTTP API 连接运行中的节点：deposit/balance/register/get/discover/search/publish/task/bid/match/result/verify/settle/dispute/arbitrate/conservation/leaderboard
- 守护进程启动逻辑提取为库函数 `node::run_daemon`，`gsn-daemon` 与 `gsn daemon` 共用同一实现

### F3 REST API

- 补全 `/api/v1/*` 完整市场端点：注册/发现/发布/投标/匹配/结果/验证/结算/争议/仲裁/充值/余额/守恒/排行/统计
- 与传输解耦的 `route(method, path, query, body)`，旧版 `/agents` `/tasks` 双兼容
- 状态码规范：业务错误 422、不存在 404、创建成功 201、OPTIONS 预检 204、坏请求 400

### F4 MCP（Model Context Protocol）

- 注册 18 个 `market_*` 工具，`tools/call` 路由到 actor 真实执行（替换原占位响应）
- stdio 传输：JSON-RPC 逐行读写，日志走 stderr，通知（无 id）不响应
- HTTP/SSE 传输：`POST` 无状态处理、通知返回 202，`GET` 提供 event-stream

### F5 市场层并发模型重构

- 市场层改为 actor + mpsc（`MarketActorHandle` 独占 `AgentMarket`）
- HTTP / MCP / CLI 经 oneshot 通道发命令，避免共享 `Mutex` 在异步事件循环中死锁
- 新增 `RegisterAgentInput`：调用方只需提供 agent_id/name 等少数字段，actor 内填充版本/时间戳/SLA/证据等级等默认值转完整 `MarketAgentCard`

## 真实网络与存储（非骨架）

- `net/peer.rs`：真实 libp2p 0.54（TCP + Noise 加密 + Yamux 多路复用 + Kademlia DHT + GossipSub）
- `storage/persist.rs`：真实 rusqlite，数据落盘到 home 下 `.gsn/data/gsn.db`
- 守护进程真实 bind P2P 与 HTTP 端口，`/health` 返回版本与运行状态

## 缺陷修复

- **数据目录字面 `~` 不展开**：`DaemonArgs` 默认 `PathBuf::from("~/.gsn/data")`，Rust 不展开 `~`，导致在工作目录下创建字面名为 `~` 的目录。新增 `default_data_dir()`（读 HOME/USERPROFILE 拼真实 home，无环境变量回退 `.gsn/data`）与 `expand_tilde()`（展开路径开头的 `~`/`~/`），解析参数后统一展开
- **POST /api/v1/agents 路由错误**：此前未区分 GET/POST 而误走统计分支，已修复
