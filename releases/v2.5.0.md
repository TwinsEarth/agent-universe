# v2.5.0 - 豆包/火山引擎方舟适配

## 一句话概述

v2.5.0 新增豆包大模型（火山引擎方舟 Ark）适配层，支持 doubao-seed-2-1 系列深度思考模型、1024K 上下文窗口。

## 模型列表

| 模型 | Model ID | 上下文 | 深度思考 |
|---|---|---|---|
| Seed21Pro | doubao-seed-2-1-pro-260915 | 1024K | ✅ |
| Seed21Turbo | doubao-seed-2-1-turbo-260628 | 256K | ✅ |
| Seed21Lite | doubao-seed-2-1-lite-260915 | 256K | ❌ |
| Doubao15Pro | doubao-1-5-pro-32k-250115 | 32K | ❌ |
| Seed16 | doubao-seed-1-6-251015 | 256K | ❌ |
| Character | doubao-seed-character | 32K | ❌ |

## 关键特性

- **base_url**: `https://ark.cn-beijing.volces.com/api/v3`
- 兼容 OpenAI Chat Completions 格式
- `thinking` 开关：仅 seed-2-1 系列支持深度思考，返回 `reasoning_content`
- `DoubaoAdapter::with_thinking(true)` 自动检测模型是否支持
- family="doubao" 接入 v2.4.7 异构协商

## 验证

- 4 个 doubao 测试全绿
- 完整 `cargo test --lib`：60 passed / 0 failed
