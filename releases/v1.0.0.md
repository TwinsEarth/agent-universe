# v1.0.0 开发日志

## 基本信息

- **版本号**：v1.0.0
- **发布日期**：2026-09-22
- **类型**：首个正式版本（Initial Release）
- **Commit**：`fce99609`

## 核心目标

搭建 GSN（Global Agent Network）最基础的 Python SDK 骨架，实现 Agent 的发现与任务调度协议。

## 新增模块

### 1. 数据模型层

**文件**：`aip-sdk-py/aip/models.py`

- `AgentCard`：Agent 身份卡
  - `did`：去中心化标识符
  - `name`：Agent 名称
  - `capabilities`：能力列表
  - `endpoints`：服务端点
  - `reputation_bps`：信誉分（基点，默认 5000 = 50%）
  - 链式构造：`AgentCard.new().with_capability()`

- `Task`：任务对象
  - 完整状态机：`PENDING → ASSIGNED → RUNNING → COMPLETED → VERIFIED → SETTLED`
  - 失败路径：`FAILED`
  - 状态迁移方法：`assign()`, `start()`, `complete()`, `verify()`, `settle()`, `fail()`

- `TaskStatus`：任务状态枚举（`str, Enum`）

### 2. DHT 后端

**文件**：`aip-sdk-py/aip/dht_backend.py`

- `MemoryDHT`：内存版 Kademlia DHT 模拟
  - `get(key) → bytes | None`：读取值
  - `put(key, value)`：写入值
  - `provide(key, peer_id)`：宣告提供
  - `find_providers(key) → list[str]`：查找提供者

### 3. 分片索引

**文件**：`aip-sdk-py/aip/index/sharded.py`

- `shard_of(did, num_shards) → int`：基于 SHA256 的分片计算
- `ShardedIndex`：分片索引管理
  - `publish_card(card)`：发布 AgentCard 到分片
  - `find_by_capability(cap) → list[str]`：按能力查找

## 技术决策

| 决策 | 原因 |
|------|------|
| 纯 Python SDK | 快速验证协议设计，不依赖 Rust |
| 内存 DHT | 单元测试无需网络 |
| SHA256 分片 | 确定性哈希，均匀分布 |
| str Enum | JSON 序列化友好 |
