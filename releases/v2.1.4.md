## 核心目标

新增 GovernorToken 合约：ERC20 代币 + 信誉注册表。

## 核心功能

### ERC20 代币

- GSP Token：GSN 生态治理代币
- 标准 ERC20 接口：transfer、approve、transferFrom
- 总量上限：10 亿

### 信誉注册表

```solidity
contract GovernorToken is ERC20 {
    mapping(address => uint256) public reputation;
    
    function updateReputation(address agent, uint256 score) external onlyVerifier;
    function getReputation(address agent) external view returns (uint256);
    function delegateVotes(address delegatee, uint256 amount) external;
}
```

### 治理投票

- 质押代币获得投票权
- 委托投票：可将投票权委托给其他地址
- 信誉与投票权关联

## 技术决策

| 决策 | 原因 |
|------|------|
| ERC20 + 信誉合一 | 减少合约数量 |
| 信誉只读接口 | 与链下信誉计算分离 |
| 委托投票 | 提高治理参与度 |
