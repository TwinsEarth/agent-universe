## 版本边界速览

- **v5.0.0 已发布**：持久化记忆系统基座 + 审核 Agent / 调配 Agent。
- **v5.0.1–v5.2.0（进行中）**：只做记忆系统——写入/检索/生命周期/隐私/完整性、集体记忆、跨会话记忆、迁移。
- **v6.0.0+（未启动）**：编队协同、委员会治理、三层协防、数值权威、多协议适配、大规模扩展。
- **v4.0.0 永不发布**：号段预留给"一切面向智能体开发"架构。
