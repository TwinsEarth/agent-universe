# v2.2.0 对等网络大版本

## 版本信息
- **版本**: v2.2.0
- **类型**: 🟢 大版本
- **核心主题**: 对等网络（Mesh）

## 核心目标
完成从星型架构到全对等 Mesh 网络的升级，实现去中心化自治。

## 核心架构

### 五层技术栈
1. **链上信任锚** - Solidity / Foundry
2. **P2P 发现** - libp2p + Kademlia DHT
3. **消息广播** - GossipSub
4. **状态同步** - CRDT
5. **数据冗余** - Reed-Solomon 纠删码

### 三栈总览
```
┌─────────────────┬─────────────────┬─────────────────┐
│   contracts/    │    gsn-core/   │   aip-sdk-py/   │
│   (Foundry)     │     (Rust)     │     (Python)    │
├─────────────────┼─────────────────┼─────────────────┤
│ ReputationBridge│ net/libp2p     │ models.py       │
│ SettlementBridge│ net/dht        │ index/sharded   │
│ CrossChainRouter│ net/gossip     │ dht_backend.py  │
│ BridgeInsurance │ net/root_seed  │                 │
│ GovernorToken   │ identity/      │                 │
└─────────────────┴─────────────────┴─────────────────┘
     链上层           P2P 网络层         SDK 应用层
```

## 新增模块

### Rust gsn-core
- identity: DID、Ed25519 签名、密钥存储抽象
- agent: AgentCard、Task 状态机
- net: libp2p 节点、Kademlia DHT、GossipSub、根种子
- chain: PoCV 可验证计算
- storage: 本地存储
- verifier: Verifier HTTP 客户端
- ffi: UniFFI、Tauri commands
- mode: 五档节点模式
- crdt: VersionVector 状态同步
- erasure: Reed-Solomon 纠删码
