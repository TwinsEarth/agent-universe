## 系统配置

### 电源策略（关键）

```bash
# 关闭所有电源配置的睡眠
sudo pmset -a sleep 0
sudo pmset -a disablesleep 1
sudo pmset -a hibernatemode 0
sudo pmset -a powernap 0
sudo pmset -a womp 1          # 网络唤醒
sudo pmset -a autorestart 1   # 断电恢复后自动开机
```

### launchd 服务管理

```xml
<!-- ~/Library/LaunchAgents/com.gsn.node.plist -->
<dict>
    <key>Label</key>
    <string>com.gsn.node</string>
    <key>ProgramArguments</key>
    <array>
        <string>/usr/local/bin/gsn-daemon</string>
        <string>--data-dir</string>
        <string>/Volumes/GSN/data</string>
    </array>
    <key>KeepAlive</key>
    <true/>
    <key>RunAtLoad</key>
    <true/>
</dict>
```

## 链上部署

### Base 主网

- 最低 gas 费：0.005 gwei
- 200,000 gas 交易成本：约 $0.002
- 部署全部合约（15 个，平均 200 万 gas/合约）：约 $0.06

### 合约部署命令

```bash
cd contracts
forge script script/Deploy.s.sol \
  --rpc-url https://mainnet.base.org \
  --account gsn-deployer \
  --broadcast \
  --verify \
  -vvv
```

## 安全策略

### 密钥管理

- 私钥存入 macOS Keychain
- 绝不明文存储
- 合约 owner 部署后立即迁移到 GSNTimelock

### 网络防护

- 只开放必要端口：22 (SSH), 4001 (P2P), 4002 (API)
- 使用 pf 防火墙
- Tailscale 组建加密 mesh 网络
