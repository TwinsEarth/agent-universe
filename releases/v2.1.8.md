# v2.1.8 轻客户端跨平台架构

## 版本信息
- **版本**: v2.1.8
- **类型**: 🔵 小版本
- **核心主题**: 跨平台轻客户端架构

## 核心目标
实现 Tauri 桌面端 + Flutter 移动端双前端，共享 Rust gsn-core 核心库。

## 新增模块

### 1. gsn-core Rust 核心库
- `identity/` - DID 身份管理、Ed25519 签名、密钥存储
- `agent/` - AgentCard、Task 状态机
- `net/` - libp2p 节点、Kademlia DHT、GossipSub
- `chain/` - PoCV 可验证计算
- `storage/` - 本地存储
- `verifier/` - Verifier HTTP 客户端
- `ffi/` - UniFFI 导出（移动端）、Tauri commands（桌面端）

### 2. Cargo features
- `full-node` - 全功能节点（默认）
- `mobile` - 移动端精简版
- `daemon` - headless 守护进程

## 技术决策

| 决策项 | 选择 | 原因 |
|--------|------|------|
| 框架选型 | Tauri 2 + Flutter | 桌面轻量，移动成熟 |
| 核心语言 | Rust | 跨平台、高性能、内存安全 |
| FFI 方案 | UniFFI | 自动生成 Swift/Kotlin 绑定 |
| 密钥存储 | 平台抽象 trait | 统一各平台安全存储 API |

## 性能指标
- 冷启动: < 1s（桌面）
- 空闲内存: 30-40 MB（桌面）
- 包体积: 2.5-10 MB（桌面）
