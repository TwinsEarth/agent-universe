# v3.7.3 — AUSec 镜像按需加载（3/9）：P2P 种子健康度确定性计算 + 每块 Ed25519 发布者锚定（patch）

## 一、交付了什么
- `gsn-core/src/ausec/seed.rs`（新增，约 560 行含 11 个测试）：
  - **种子健康度确定性计算**（不联网、不推断对端）：
    - `ChunkSeedHealth::from_replicas`：健康度 = 副本数 × 100（0→0%、1→100%、
      10→**1000%**），`available`=至少 1 副本，`meets_seed_target`=≥10 副本。
    - `ImageSeedHealth::for_manifest`：整镜像按**最弱块**（min 副本数）决定整体健康度，
      避免平均掩盖冷块；`availability_permille` 用千分点整数（不引浮点），缺记按 0 副本；
      空镜像 availability=1000 但 `fully_available=false`（不声称能服务空镜像）。
    - `ReplicaLedger`：按块内容地址（sha256）登记观测副本数，驱动健康度计算。
  - **每块 Ed25519 发布者锚定**：
    - `chunk_attestation_message`：域前缀 `AUSEC-CHUNK-ATTESTATION-V1\n` +
      长度自描述的 `image/index/offset/length/sha256`，防歧义解析与**槽位迁移**
      （把 A 块的有效证明搬到 B 槽位必失败）。
    - `sign_chunk` / `sign_chunk_with_keypair`：复用仓库既有 `identity` 的
      `Keypair` / `Ed25519Signer`，不重复 dalek 样板。
    - `verify_chunk_attestation`（锚定）+ `verify_trusted_chunk`（锚定后查信任集合）。
    - `PublisherId`（32B 公钥）、`TrustedPublishers`（HashSet，**空集合=谁都不信**
      fail-closed）。
  - **真实生产接线点 `AttestedSeedSource`**（非测试专用）：实现 `BlockSource`，包在
    任意源外；取块时强制读旁路签名 `<dir>/<sha256>.sig`（64B）：
    缺证明 → `Attestation`（不是 NotPresent，不被当普通降级跳过）、
    坏签名/槽位不符 → `BadAttestation{index}`、
    发布者不受信 → `UntrustedPublisher{index}`；
    三者在 `BlockStore::get_chunk` 中**立即 return 安全硬错误，不降级到其它源**。
    `write_chunk_signature` 提供做种写签名工具。
- `ausec/blockstore.rs`：`BlockFetchError` 新增 `Attestation(String)` /
  `UntrustedPublisher`；`BlockStoreError` 新增 `BadAttestation{index,reason}` /
  `UntrustedPublisher{index}`，`get_chunk` 两分支 fail-closed。
- `ausec/mod.rs`：导出 seed 类型；系统插件 `com.twinsearth.sys.ausec` 新增两个
  **只读** PMB 方法：
  - `seed_health`：入参 `{manifest, replica_counts:{"<idx>":n}}`，返回确定性健康度 JSON；
  - `chunk_attestation_verify`：入参
    `{image, entry, publisher:hex32, signature:hex64, trusted_publishers:[hex...]}`，
    先锚定验签再查信任集合，任一不过返回错误。

## 三、诚实边界
- **不伪造跨网络**：本版不实现任何 P2P 传输；远程块仍由内层
  `UdosRemoteBlockSource` 具名 `RemoteNotImplemented`，健康度只按调用方给出的
  副本**观测计数**做确定性计算，不假装连到对端。
- 外部实测数字（镜像访问面 4.2–13.3%、按需 1.71×、磁盘写降 57%、约 90% 沙盒
  CPU<5%、超卖 50×、virtio-pmem/DAX 降 40.2%、DAMON+balloon 再降 21.2%、
  时延影响 45.2%→17.3%、种子 1000% 健康度）均来自 **aiwiki.ai / byteiota.com
  对 DSEC 的报道，非本仓复测**；本仓只交付可复算模型与单测，见
  `docs/ausec/AUSEC-DESIGN.md`。
- 签名只锚定「发布者对块内容与槽位的声明」；字节==sha256 仍由外层 `BlockStore`
  用清单统一复核，二者构成双保险。信任根是**本地** `TrustedPublishers`，本版不做
  链上信任锚定/吊销分发（属后续版本）。
- `AttestedSeedSource` 的旁路签名约定（`<dir>/<sha256>.sig`）是真实可用的生产
  接线，但当前仓库不内置签名分发服务。
