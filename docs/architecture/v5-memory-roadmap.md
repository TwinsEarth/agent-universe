## 一、v5.0.x：记忆的写入、检索与生命周期（9 个小版本）

| 版本 | 主题 | 核心交付 |
|---|---|---|
| v5.0.1 | **自动记录接线** | daemon 在任务执行后自动构造 `MemoryEntry` 并追加 `memory.jsonl`；CLI `gsn memory` 与 daemon 数据目录一致 |
| v5.0.2 | **记忆检索** | 按 gate / task_id / tags / 时间 / 退出码过滤；`gsn memory query` 支持组合条件与结论摘要 |
| v5.0.3 | **轮转与容量** | 实测 `max_bytes` / `keep_rotated` / 字节上限触发轮转；轮转文件可 `load_all` 检索 |
| v5.0.4 | **隐私审核** | 记忆写入前经审核 Agent，命中 secret 即 fail-closed 拒绝入记忆（与 v5.0.0 auditor 接线） |
| v5.0.5 | **字段级脱敏与最小化** | stdout/stderr tail、argv、cwd 逐字段脱敏；按最小必要保留（MMP 字段级思想，先脱敏再落盘） |
| v5.0.6 | **节点画像** | 调配 Agent 从记忆中聚合节点历史（耗时/成功率/能力），更新 `NodeProfile` |
| v5.0.7 | **记忆驱动调度** | 调度决策参考历史记忆（历史成功率/延迟），而非仅当前负载/静态延迟 |
| v5.0.8 | **会话摘要** | 会话级压缩，原始转录留主机、仅摘要上行；摘要条目入记忆 |
| v5.1.0 | **完整性** | 记忆条目哈希链（前一条哈希 → 后一条），落盘可检测篡改/缺行 |

## 二、v5.1.x：集体记忆与跨 Agent / 跨会话（10 个版本）

| 版本 | 主题 | 核心交付 |
|---|---|---|
| v5.1.0 | **集体记忆基座** | `fleet-memory` 共享存储与策展（facts / decisions / open problems），角色化读写 |
| v5.1.1 | **CAT7 记忆块** | 七字段认知记忆块模式，作为跨 Agent 记忆交换的标准单元 |
| v5.1.2 | **SVAF 字段级评估** | 接收方逐字段评估/接受，而非整条接受或拒绝 |
| v5.1.3 | **lineage 血缘** | 内容哈希键的父/祖先链，声明可追溯来源 |
| v5.1.4 | **remix 再混合** | 仅存储接收方自己的角色评估理解，不存储原始同伴信号 |
| v5.1.5 | **环境痕迹/快照接续** | `pack_diff` 快照即环境痕迹，Agent 可从第 k 步接续，仅记录后续变化 |
| v5.1.6 | **记忆巩固** | 短期（TTL）→ 中期（快照）→ 长期（分布式存储 + Merkle-SHA256）三阶段 |
| v5.1.7 | **主动遗忘** | FadeMem 式自适应衰减/淘汰，降低存储、保持检索质量（存储收益数字实测，不预设） |
| v5.1.8 | **可移植记忆** | `token_budget` 预算规划 + 相关性分级（原文/摘要/丢弃），跨会话迁移与来源校验 |
| v5.1.9 | **记忆治理** | 防 MemClaw 四失败模式（未授权泄漏、陈旧传播、矛盾持久化、来源坍缩） |

## 三、v5.2.0：稳定化与多平台真机验证

- 跨平台（macOS / Windows / Linux）真机：记忆写入、检索、轮转、隐私、完整性、跨会话迁移的端到端验证。
- 记忆系统性能基准：append 吞吐、query 延迟、轮转开销、存储占用（数据来自实测，不引用未核验数字）。
- 文档、版本一致性、Release 全流程收尾。

## 四、执行纪律

1. **每版闭环**：写代码 → 单测/集成测试 → `cargo fmt` / `clippy -D warnings` / `test` 本地全绿 → PR → CI 全绿 → squash merge → annotated tag → GitHub Release。
2. **不发 v4.0.0**：v4 号段预留给"一切面向智能体开发"架构；当前在 v5 序列。
3. **记忆之外不越界**：v5 内不提前实现编队/委员会/协防/数值权威/多协议；发现确实需要上述能力才能推进时，先记录为 v6 依赖，不擅自落地。
4. **数字诚实**：任何性能/收益数字来自本仓实测或已核验一手论文，标注口径；无法确认则标"待核验"。
5. **只改本项目**：仅在 TwinsEarth/agent-universe 内开发，不碰 NewAgentUniverseByDeepSeek 及其他项目。
