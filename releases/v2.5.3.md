# Agent Universe v2.5.3 — Mesh 自组网 & 网络增强

**发布日期**: 2026-09-26
**版本号**: gsn-core 0.2.53 / npm 2.5.3

## 核心变更

### 新增 `mesh/` 模块：跨网络、跨主机、跨系统自组网

| 子模块 | 文件 | 功能 |
|---|---|---|
| 心跳 | `mesh/heartbeat.rs` | 定期探测 peer 存活，Online/Suspicious/Offline 三态自动转换 |
| 嗅探 | `mesh/discovery.rs` | 自动发现本地网络 peers，DiscoveryAnnouncement 广播上线信息 |
| 会话 | `mesh/session.rs` | 分配临时 SN 唯一识别码，绑定/解绑永久 DID，历史会话追踪 |
| 自组网 | `mesh/mesh.rs` | MeshNode 组合心跳+嗅探+会话+NAT穿透，拓扑快照 |

### 网络增强 API

| 端点 | 方法 | 功能 |
|---|---|---|
| `/api/v1/network/peers` | GET | 列出已连接对等节点 peer_id |
| `/api/v1/network/info` | GET | 本机 peer 信息（peer_id/连接数/监听地址/bootstrap） |
| `/api/v1/network/bootstrap` | POST | 添加 bootstrap 节点，发起自组网连接 |

### 心跳机制

- **HeartbeatConfig**: 间隔 15s，超时阈值 3 次，探测超时 5s
- **PeerLiveness**:
  - `Online`: 最近一次心跳成功
  - `Suspicious`: 有心跳丢失但未超阈值（仍算可用）
  - `Offline`: 连续丢失 ≥3 次，确认离线
- 收到 pong 自动重置 miss 计数，记录 RTT

### 临时 SN & 永久 DID 绑定

- **SessionId**: 格式 `SN-{:06}-{code}`，自增序号 + 随机码
- peer 首次上线分配临时 SN
- 绑定永久 DID 后建立映射，同一 DID 多次会话累计计数
- 会话结束解绑，DID 离线

### 三机自组网场景

```
Mac mini (macOS, 根种子)
    ↕ libp2p TCP + Noise
Cloud Linux (云电脑, 开发主机)
    ↕ libp2p TCP + Noise
Windows PC (TwinsEarth, 部署测试)
```

每台机器：
1. 启动后自动嗅探本地网络
2. 发现 peers 并注册心跳
3. 分配临时 SN
4. 绑定永久 DID
5. NAT 穿透建立连接
6. 形成 mesh 网状拓扑
