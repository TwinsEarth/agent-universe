# v2.7.9 — 沙箱安全边界

把 v2.7.6 的策略类型落到可调用的检查：网络策略、审计日志、权限、证据分级。

## 新增：sandbox/security.rs

### 网络策略落地：NetworkGuard

- `check_egress(host, port)`：默认拒绝；`allow_egress=false` 直接拒绝；
- `deny_raw_ip` 时拒绝裸 IP（v4/v6）；
- 白名单精确匹配 `host:port`，支持 `:*` 端口通配、`*.domain` 子域通配、`*` 全通。

### 审计日志：AuditLog

- `append(AuditEntry)`：append-only，不可删改；配置文件时以 JSON Lines 追加落盘；
- `for_sandbox(id)` 按沙箱过滤；`entries()/len()`。

### 权限检查：PermissionChecker

- `check(held_scopes, required)`：scope 精确匹配，支持 `*` 全权，缺失返回 IsolationViolation。

### 证据分级：EvidenceGrade

- 三级（Unverifiable / Unverified / Verified），有序，`meets(required)` 判定门槛；
- 以 lowercase 字符串序列化（落盘/传输可读）。

## 实机验证（tests/v279_test.rs，13 项）

- 默认拒绝出站；白名单匹配放行，非白名单/端口不符拒绝；
- 端口通配、子域通配；裸 IP 拒绝；raw IP 检测（v4/v6/域名）；
- 证据分级排序与门槛；
- 审计内存 append/过滤；审计落盘 JSON Lines 且含 "verified"；
- 权限 scope 精确匹配、`*` 通配、缺失拒绝。
