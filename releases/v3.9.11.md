## 一、定位

v3.9.11 是 v3.9.x 小版本序列的 **Windows 真机回归验证版（parity/validation release）**，不是新功能大版本。
资源市场 MVP 仍属预留的 v4.0.0（「一切面向智能体开发」架构），本版本不触碰；密码学实现（Ed25519
治理签名、PoCV、EVM 轻客户端等）仍标注「需外部审计」。

v3.9.10 在 Mac mini（Apple Silicon）上完成真机缺陷修复（纠删码发起端落地、分片放置限定 gsn 协议子网、
治理签名 CLI 对齐、SIGTERM/SIGINT 可靠退出）。本版本在 **Windows 10 x64 真机**用同一套发布源码做对等性
端到端回归，确认这些修复与全部核心数据面在 Windows 上同样成立，并补齐此前未在 Windows 上取证的
「硬终止掉线检测 → 同身份重连 → 账本/任务/nonce 重启恢复」完整时序。

- 版本号：npm **3.9.11** ↔ gsn-core / gsn-daemon **0.3.101**（规则 0.X.(Y*10+Z)，9*10+11=101）。
- 除版本声明点外，本版本**不包含运行时代码行为变更**；版本差异是新增的 Windows 真机证据与本说明。
  全量 Rust 关卡（fmt / clippy -D warnings / test / release build）在 Windows 上重新通过，见第四节。

安全负面（fail-closed，逐项真实攻击取证，均未入账、守恒恒为 1350、cli 余额恒 50）：

1. 重放：固定 nonce 信封重复提交 → `GOV_REPLAY: nonce nonce-cli-1 已被消费过（重放）`。
2. 篡改目标：保留原签名、把 target 正则改为 `did:nau:0000…` → `GOV_BAD_SIGNATURE`（验签先于去重，篡改 target 不会落到 replay 分支掩盖签名失败）。
3. 过期：旧信封先撞 `GOV_EXPIRED`（校验顺序：成员 → capability → 时间窗 → 验签 → nonce）。
4. 质押不足：stake=99 克隆卡片直 POST `/api/v1/agents` → HTTP 422（MIN_STAKE=100）。

## 五、设计边界（如实记录，非缺陷、本版本不改）

- `/api/v1/agents`、`/api/v1/tasks` 为**节点本地视图**：跨节点业务实体（agents/tasks）当前版本不复制。
  注册 agent 仅向 DHT 写 `/aip/agent/{id}` 索引（`DhtPut`），`/network/find` 是 Kademlia `find_node`
  返回 closest_peers，并不读取 value，也无消费端点；GossipSub 的 gsn/agents、gsn/tasks 主题只订阅、
  未承载业务数据。因此 n2/n3 上 GET agents 返回 0、GET 跨节点任务返回 404 属预期。跨节点业务复制是
  **尚未实现的能力**，Mac 同码同行为，不是 Windows 回归，不在本版本改动共识/架构去「修复」。
- 服务端卡片规范化与 Mac 一致（pricing.price=0、evidence_grade=Unverified、version 归一为包版本、
  时间戳归一）：以服务端权威字段为准，中文 name/description 正确存储（PowerShell 控制台显示为代码页
  现象，JSON 数据为 UTF-8，无数据损坏）。

## 六、诚实声明：本版本未覆盖项

以下在 Mac/Windows 均未真机取证，不作为本版本结论：任务后半程 bid→match→result→verify→settle 全链
（verify 载荷需 members+signed_votes，当前夹具不具备）；CRDT 多节点显式收敛（当前版本未定位到 REST 写面）；
50 节点规模、10 节点 20% 恶意、1+2 强分区、24h CRDT 增长、100 Sybil；真实链上交易 / EIP-3009 /
Paymaster / x402；Docker build/up；全 workspace（含 Tauri 客户端）测试。PoCV 仅证明归属与未篡改，
不证明通用计算正确性。以上列入后续版本计划，不以测试通过名义发布。
