# TwinsEarth 论文归档索引（docs/papers）

本目录统一归档 TwinsEarth / UDOS / Agent Universe 论文体系的**全部论文 PDF**，按论文编号命名、去重、取最新权威版本。

## 归档规则

- **命名**：`<编号>_<标题>.pdf`；P0c 为三语版（全中文 / 中英双语 / 全英文）。
- **去重**：跨版本（v7.5.0 / v7.6.0 / v7.7.x、_pkg / _darkbuild / scratch 等）重复副本只保留一份权威成品。
- **来源卷**：标注每篇论文首次收录的论文卷版本。
- **P0d** 为 2026-09-24 新增旗舰论文，markdown 源文件与 PDF 同目录；其「群体记忆量化收益」由可复现对照实验替换，详见 P0d 文末附录 A。

## 证据等级定义

| 等级 | 含义 |
|---|---|
| verified | 真机实测 / 独立验证可复现 |
| cpu-proto | CPU 合成机制原型、受控实验或数学推导外推（机制成立，规模/口径受限） |
| unverified | 引用论文/厂商口径，本工程未实测 |
