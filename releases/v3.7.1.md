# v3.7.1 — AUSec 镜像按需加载（1/9）：内容寻址镜像块清单 + 完整性基线（patch）

v3.7.1 是 AUSec「跨网络 P2P 超大规模沙盒」九连版的第一个补丁。v3.7.0 交付了「在什么
后端、以什么隔离强度运行」的选择层；本版开始解决「镜像从哪来、怎么按需取」的第一步：
把一个镜像描述成**严格连续布局的定长块序列**，每块带自己的 SHA-256 内容地址，并提供
结构完整性基线与按需取块后的字节校验。

总体方案见 [`docs/ausec/AUSEC-DESIGN.md`](../docs/ausec/AUSEC-DESIGN.md) §3.1（3.7.1）。

## 一、交付了什么

| 交付物 | 位置 | 性质 |
|---|---|---|
| 块条目 `ChunkEntry{index,offset,length,sha256}` | `gsn-core/src/ausec/image.rs` | 内容地址 + 严格布局 |
| 块清单 `ChunkManifest{image,chunk_size,total_length,chunks}` | 同上 | 序列化结构 |
| 构建 `build_manifest(image,data,chunk_size)` | 同上 | 定长切块 + 每块 SHA-256 |
| 结构基线 `validate()` / `parse_and_validate()` | 同上 | 入场闸 |
| 按需校验 `verify_chunk()` / `verify_image()` | 同上 | 对实取字节重算摘要 |
| PMB 方法 `manifest_validate` | `ausec/mod.rs` | 系统插件只读准入 |

## 二、完整性基线（按需取块前的唯一入场闸）

`validate()` 逐条强制：

1. `image` 非空；`chunk_size` 在 `1..=64 MiB`（防畸形清单诱导一次性巨量分配）。
2. 块序号 `index` 从 0 开始且**严格等于其位置**（顺序不可乱）。
3. 偏移 `offset` 从 0 开始**严格连续**——与「非末块必须恰为满块」合起来保证
   **无空洞、无重叠**。
4. 每块长度 `> 0`；非末块恰为 `chunk_size`，末块不超长。
5. `sha256` 必须是 **64 位小写十六进制**（强制规范化，拒绝大写/非 hex）。
6. `total_length` 必须等于按布局累加的长度。
7. 空镜像是**零块、总长 0** 的合法空清单；非零总长 + 零块直接拒绝。

## 三、按需取块校验（缺块即取、坏块即拒）

- `verify_chunk(index, bytes)`：序号必须在范围内、字节数与清单一致、重算 SHA-256 等于
  声明的内容地址；错长→`ChunkLengthMismatch`，篡改→`ChunkDigestMismatch`，越界→
  `ChunkIndexOutOfRange`。
- `verify_image(bytes)`：总长一致后，按每块偏移/长度切片逐块校验，任何坏块具名报错。

这为 v3.7.2 的 BlockStore 提供了契约：**本地只存元数据，真正需要某块时才取；取回来的
字节必须过 `verify_chunk`，过不了就不允许进入本地缓存**。

## 四、系统插件接线（真实调用点）

`com.twinsearth.sys.ausec` 新增只读 PMB 方法 `manifest_validate`，入参 `{manifest}`，
合法返回 `{valid:true,image,chunk_size,chunks,total_length}`，结构非法/坏 JSON/缺字段
均类型化拒绝。它是 BlockStore 接受任何远端或本地清单前的**唯一 PMB 入场路径**，不是
死代码。

## 六、诚实边界（不夸大）

- 本版**不联网拉取任何块**，也不实现本地块缓存——那是 v3.7.2 的 `BlockStore`。
- 本版**不验证块的发布者身份**：SHA-256 只证明「字节与清单声明一致」，无法证明清单
  来自可信发布者。每块 Ed25519 签名 + 发布者公钥锚定在 **v3.7.3** 落地；在那之前，
  清单的可信分发通道由调用方负责，本版不冒充「已防恶意镜像源」。
- 外部数字（镜像实际访问占比 4.2–13.3%、按需加载约 1.71×、磁盘写降约 57% 等）仍为
  外部实测，来源 `aiwiki.ai/wiki/dsec#2` 与
  `byteiota.com/deepseek-dsec-agent-training-sandbox/#1`，**非本仓复测**。
