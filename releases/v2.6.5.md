# Agent Universe v2.6.5 — Topology Truth（分层拓扑确定性重写）

> 发布日期：2026-09-28 · gsn-core 0.2.65

## 主题

按 GAP-ANALYSIS §5.2 / §5.3 / §5.4 / §5.7 重写分层拓扑，消除「测试把常量固化成正确」「拓扑依赖 HashMap 随机迭代序」「跳数恒为 7」三处网络拓扑缺陷。

## 改动

### §5.2 route_hops 不再恒为 7
此前 `route_hops` 对每一对跨房间节点都返回 `Some(Level::depth()) = 7`，忽略两房间实际聚合深度、可达性，且测试 `==Some(7)` 把常量钉死。现在按两房间在聚合树中的**最近公共祖先（lca）**真实计算：

- 未注册节点 → `None`；
- 自己 → 0；同房间邻居 → 1；
- 跨房间 → `2·(lca-1)`：两房间向上逐层 `÷fanout`，直到桶相等。

fanout=9、500 节点下：同 Lv2 组两房间 = 2 跳，跨 Lv2 组 = 4 跳——距离越大跳数越大，不再是常量。

### §5.3 边数测试补规模对照
原 `edges_are_linear_not_quadratic` 只断言 `edges < N²/100`，任何「次 N²/100」结构都能通过，名为测增长率却不比较 N 与 2N。新增 `edges_scale_linearly_not_quadratically`：N 从 10k 翻倍到 20k，edges 必须约翻倍（比值 < 2.5），证明线性而非二次。`logical_edges` 改为 O(1) 公式（满房 f(f-1)/2 + 尾房 + N 条上行边）。

### §5.4 房间归属确定性化，join 不再 O(depth·N)
此前 `leaf_groups` 是 `HashMap`，`join` 选「第一个未满房间」依赖 HashMap 随机迭代序，且每次 join 都 `promote()` 全量重分桶。现改为：

- 节点存入 `BTreeSet<String>`（字典序），房间号 = `rank(fanout)`；
- **与插入顺序无关**：新增 `topology_is_insertion_order_independent` 用 500 个 id、正序与逆序两种插入构建，房间数 / 边数 / 全部 route_hops 逐一对等；
- `join` 退化为一次 `BTreeSet::insert`（O(log N)），构造不再超线性；
- `fanin_of` 补回此前漏算的 1 条上行边（注释却声称含父代表），扇入上界 = fanout。

### §5.7 协议版本唯一来源
`net/peer.rs` Identify 与 `mesh/mesh.rs` MeshConfig 此前分别硬编码 `/gsn/0.2.64`、`gsn/0.2.53`（互相漂移）。全部改为 `env!("CARGO_PKG_VERSION")`，随 `bump-version.sh` 自动一致，杜绝协议版本漂移。
