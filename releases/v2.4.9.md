# v2.4.9 - 多模型适配层：OpenAI / Gemini / Anthropic

## 一句话概述

v2.4.9 在 v2.4.8 DeepSeek 适配层基础上，新增 OpenAI Chat Completions、Google Gemini、Anthropic Messages 三大模型后端适配，每个后端精确复刻官方 API 格式，并统一接入 v2.4.7 异构 LLM 协商系统。

## 四大后端全景

| 后端 | family | 代表模型 | 上下文窗口 | system 角色位置 |
|---|---|---|---|---|
| OpenAI | `openai` | gpt-4o / gpt-4o-mini / gpt-4-turbo / o1 | 128K–200K | messages[].role=system |
| Gemini | `gemini` | gemini-1.5-pro / flash / 2.0-pro | 1M | 顶级 `system_instruction` |
| Anthropic | `anthropic` | claude-sonnet-4 / opus-4 / haiku-4 | 200K | 顶级 `system` 字符串 |
| DeepSeek | `deepseek` | deepseek-chat / reasoner | 64K | messages[].role=system |

## 子模块

### openai.rs — OpenAI Chat Completions

- `OpenAiModel` 枚举：Gpt4o / Gpt4oMini / Gpt4Turbo / O1，各自的 model 字符串与上下文窗口。
- `OaMessage` / `OaRole`：system / user / assistant / tool 四角色。
- `OaChatRequest`：标准 OpenAI Chat Completions 请求体。
- `OpenAiClient` trait + `MockOpenAiClient`：CPU 原型不发网络。

### gemini.rs — Google Gemini generateContent

- `GeminiModel`：Gemini15Pro / Gemini15Flash / Gemini20Pro，1M 上下文窗口。
- 关键差异：**无 system 角色**，system 作为顶级 `system_instruction` 参数；消息 role 是 `user` / `model`（不是 assistant）；内容在 `content.parts[].text`。
- `GeminiClient` trait + `MockGeminiClient`。

### anthropic.rs — Anthropic Messages API

- `AnthropicModel`：ClaudeSonnet4 / ClaudeOpus4 / ClaudeHaiku4，200K 上下文。
- 关键差异：**system 是顶级字符串参数**（不在 messages 里）；`max_tokens` 必填；响应是 `content[].text` blocks 而非 choices。
- `AnthropicClient` trait + `MockAnthropicClient`。

### adapter.rs — 统一适配器接入异构协商

- `OpenAiAdapter` / `GeminiAdapter` / `AnthropicAdapter`：各自包装 Mock 客户端，`chat()` 返回统一 `LlmResult { answer, prompt_tokens, completion_tokens }`。
- `as_llm_model(id, weight)`：产出 `family="openai"/"gemini"/"anthropic"` 的 `LlmModel`，直接加入 v2.4.7 `Deliberation`。
- `propose(model_id, confidence)`：便捷产出 `Proposal`，供协商会话收集异构提案。
- `LlmBackend` 枚举：统一标识四大家庭（openai / gemini / anthropic / deepseek）。

## 与 v2.4.7 异构协商的集成

```
Deliberation（v2.4.7 加权投票）
  ├── LlmModel { family: "openai",   weight: 0.9  }  ← OpenAiAdapter
  ├── LlmModel { family: "gemini",   weight: 0.8  }  ← GeminiAdapter
  ├── LlmModel { family: "anthropic",weight: 0.85 }  ← AnthropicAdapter
  └── LlmModel { family: "deepseek", weight: 0.7  }  ← DeepSeekAdapter（v2.4.8）
        │
        └── 各 Adapter::chat()
              ├── 精确复刻各家请求格式
              └── Mock 客户端返回固定答案（CPU 原型）
```

## 验证

- 13 个新 llm 模块测试全绿（openai 2 + gemini 3 + anthropic 3 + adapter 5）。
- 完整 `cargo test --lib`：**53 passed / 0 failed**。
- 编译零 warning。

## 边界声明

- 所有客户端为 Mock，不发真实 HTTP；生产环境实现对应 trait 即可接入真实 API。
- token 用量为硬编码估算，非真实计费。
- 未处理流式响应（stream: false）；流式支持留待后续。
- Gemini model 名在 URL path 中（如 `/models/gemini-1.5-pro:generateContent`），不在请求体里。
