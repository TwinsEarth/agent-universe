## 核心目标

修复 ReputationBridge.syncReputation 缺少 MAX_REPUTATION 校验的问题。

## 问题描述

在 v2.1.0-v2.1.5 中，`syncReputation()` 函数更新信誉分时，没有校验上限值。

风险：如果跨链消息被操纵，信誉分可能被设置为超过最大值，导致：
- 信誉分溢出（虽然 Solidity ^0.8 有溢出检查）
- 高信誉 Agent 获得不公平优势
- 信誉系统可信度下降

## 修复方案

```solidity
uint256 public constant MAX_REPUTATION = 10000;

function syncReputation(address agent, uint256 score) external onlyRouter {
    require(score <= MAX_REPUTATION, "Score exceeds maximum");
    reputation[agent] = score;
}
```

## 技术决策

| 决策 | 原因 |
|------|------|
| MAX_REPUTATION = 10000 | 基点制，100% 信誉分 |
| 链式校验 | 防止异常值进入系统 |
| onlyRouter 修饰符 | 只有路由合约能调用 |
