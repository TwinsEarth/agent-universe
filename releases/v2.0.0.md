# v2.0.0 开发日志

## 基本信息

- **版本号**：v2.0.0
- **发布日期**：2026-09-22
- **类型**：大版本（Major Feature Release）
- **Commit**：`758aae18`

## 核心目标

从单分片升级到多级分片架构，支持地理位置分片和分片合并，为百万级 Agent 网络做准备。

## 新增模块

### 1. ShardMetadata 元数据结构

**文件**：`aip-sdk-py/aip/index/sharded.py`

```python
@dataclass
class ShardMetadata:
    capability: str
    region: str = "GLOBAL"
    num_shards: int = 1
    version: int = 1
    max_per_shard: int = 500
    counts: dict[int, int] = field(default_factory=dict)
```

- 序列化/反序列化：`to_bytes()` / `from_bytes()`
- JSON 友好：counts 的 key 转为字符串

### 2. 地理位置分片

DHT key 设计：
```
/aip/cap/{capability}/r/{region}/meta    # 元数据
/aip/cap/{capability}/r/{region}/s/{sid}  # 分片数据
```

Agent 发布时自动路由到所属区域分片，查找时遍历该区域所有分片。

### 3. 分片合并机制

- 低负载分片可合并
- `max_per_shard = 500` 为容量阈值
- `version` 字段记录分片结构变更历史

## 技术决策

| 决策 | 原因 |
|------|------|
| ShardMetadata 持久化到 DHT | 新节点加入时可从 DHT 恢复分片结构 |
| region 参数 | 跨区域 Agent 发现时减少查询量 |
| counts 记录 | 为后续自动分裂/合并提供数据 |
