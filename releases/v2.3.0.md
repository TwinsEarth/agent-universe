# v2.3.0 - P2P（分布式网络基础）

> 发布日期：2026-09-20
> 代号：P2P
> 类型：功能版本（minor）

## 一句话简介

P2P 分布式网络基础层：libp2p 网络栈、Kademlia DHT、GossipSub、根种子引导、五种节点模式。

## 核心内容

### 网络栈
- `net/libp2p_node.rs`：libp2p host 初始化，Noise + Yamux + QUIC
- `net/dht.rs`：Kademlia DHT 客户端，节点发现与内容路由
- `net/gossip.rs`：GossipSub 发布/订阅，消息广播
- `net/root_seed.rs`：根种子引导逻辑，自动降级机制

### 节点模式
- `mode/mod.rs`：五种节点模式
  - Archive：全量存储，DHT 服务端
  - Full：全量 AgentCard，DHT 客户端
  - Light：仅索引，GossipSub 订阅
  - Edge：最近任务，按需连接
  - Browser：WASM，仅签名与查询

### 网络拓扑
- `topology/`：邻居管理、图结构、随机游走
