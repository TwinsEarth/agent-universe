# v3.5.7 — MSRV 诚实化：显式声明并实测最低工具链 1.88.0（#75 / W-01）

v3.5.7 是 v3.5.6 之后的**补丁版本（patch）**。它回应审计项 **W-01**：历史文档/CI 曾把
最低 Rust 版本写成 1.85.0，但锁定依赖（`icu` / `idna` / `time` 等）实际要求更新的
编译器——声明与事实不符。本版把最低支持 Rust 版本（MSRV）变成**可证实、有 CI 关卡**
的属性，而不是写在文档里的愿望值。**不含功能变更、不改变任何运行时行为。**

## 一、下限是算出来、再实测的，不是猜的

1. **从锁定依赖计算声明下限**：遍历 `Cargo.lock` 解析出的 385 个包，读取每个包自带
   的 `rust-version`，取最大值。最高的是 **`time` 0.3.55 / `time-core` 0.1.9 /
   `time-macros` 0.2.32 家族要求的 `1.88.0`**；其后是 `wasip2` 要求 1.87、
   `uuid 1.26.1` / `hashbrown 0.17.1` / `deranged` 要求 1.85。
2. **实测**：安装 `rustc 1.88.0`（2025-06-23），在离线、锁定依赖下执行
   `cargo +1.88.0 check --bins --locked`，**4m40s 编译通过、EXIT 0**（库 + 两个二进制）。

因此 `gsn-core` 的 MSRV 定为 **1.88**——低于它，依赖树本身就无法编译。

## 二、改动

| 项 | 内容 |
|---|---|
| `gsn-core/Cargo.toml` | 新增 `rust-version = "1.88"`，并注明下限来源（time 家族）与「已实测、CI 有 MSRV 关卡」。 |
| `.github/workflows/ci.yml` | 新增独立 job **`rust-msrv`（Rust MSRV 1.88.0，ubuntu）**：装 1.88.0 工具链，执行 `cargo check --bins --locked`。依赖若在未来升级到需要更新的编译器，此关卡会立刻变红，而不会让 MSRV 悄悄失真。 |
| 文档 | 本发布说明即为权威记录；MSRV 口径与「为什么只 check 库/二进制」一并写明。 |

### 为什么 MSRV 关卡只跑 `check --bins`，不跑测试与 clippy

MSRV 约束的对象是**发布给用户的库与二进制**。测试与 lint 用到的 `dev-dependencies`
（proptest、clippy 等）可能要求更新的编译器；若用它们抬高发布产物的 MSRV，会无意义地
限制下游使用者。因此约定：**产物（lib + bins）必须在 1.88 编译；测试、clippy、fmt
继续以 stable 运行**（CI 的 `rust-test` job 不变）。

## 三、作用域与诚实边界

- 仅对核心 crate `gsn-core` 声明 MSRV。两个 Tauri 桌面壳（`client/src-tauri`、
  `desktop/src-tauri`）依赖 Tauri/WebView 工具链，其可用 Rust 下限由 Tauri 决定，
  本版不代其声明，避免再次出现「写了但不成立」的数字。
- 该下限绑定**当前 `Cargo.lock`**。依赖升级后应由 CI 的 MSRV 关卡重新证明，而非手改。
- 本版无 Rust 生产代码变更，无新增/修改测试；验证以 1.88 实测编译 + stable 全量回归为准。
- 本版不含任何 push / tag / Release 资产操作；v3.5.0 tag 与既有 Release 资产不动。

## 四、验证（Linux 云沙箱，4 核 / 8 GB）

| 关卡 | 结果 |
|---|---|
| `cargo +1.88.0 check --bins --locked -j2`（rustc 1.88.0） | **EXIT 0**（4m40s，库 + gsn / gsn-daemon 两二进制） |
| 依赖 `rust-version` 扫描 | 385 包中 269 个声明，最高 = time 家族 **1.88.0** |
| `cargo +stable test --workspace -j2` | 全量回归（见提交记录，基线 627，本版无测试增删） |
| `cargo metadata --locked` | 通过（gsn-core = 0.3.57） |
| 版本一致性 | npm 3.5.7 ↔ gsn-core 0.3.57（10 个声明点） |
