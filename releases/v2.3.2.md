# v2.3.2 - Protocol（MCP + ACA 兼容层）开发日志

> 发布日期：2026-09-22
> 版本：v2.3.2
> 前置版本：v2.3.1（Swarm 群体智能）

---

## 一、版本目标

在 v2.3.1 群体智能基础上，增加 MCP（Model Context Protocol）和 ACA（Agent Communication Architecture）兼容 API 接口与通讯协议。

核心命题：**百万级 Agent 的瓶颈是协调而非单体智能。** 五堵墙（协调、信任、验证、激励、治理）全是组织问题。

## 二、新增模块

### 2.1 MCP 兼容层（`mcp/`）

兼容 MCP 2024-11-05 规范，GSN 节点可作为 MCP Server 暴露能力，也可作为 MCP Client 调用外部工具。

| 文件 | 内容 |
|------|------|
| `protocol.rs` | JSON-RPC 2.0 消息、7 种标准方法、错误码 |
| `tool.rs` | ToolDefinition / ToolParameter / ToolResult |
| `resource.rs` | ResourceDefinition / ResourceContents / ResourceUri |
| `prompt.rs` | PromptDefinition / PromptMessage / 苏格拉底式渲染 |
| `server.rs` | McpServer（完整的 initialize/list/call 处理链） |

### 2.2 ACA 通讯协议层（`aca/`）

实现四个协议对象的最小闭环：

```
Agent Manifest → Task Envelope → Receipt → Reputation
    发现      →     执行      →   验证   →   结算
```

| 文件 | 内容 |
|------|------|
| `manifest.rs` | AgentManifest（智能体磁力链）+ HardwareProfile |
| `envelope.rs` | TaskEnvelope（CID、验证策略、隐私、预算） |
| `receipt.rs` | Receipt（结果哈希、资源计量、TEE/zk 证明） |
| `reputation.rs` | MultiReputation 四维声誉（不可转让） |
| `verification.rs` | 五级验证分层 L0-L4 + 经济决策 |
| `message.rs` | AcaMessage 12 种消息类型 |

## 三、五级验证分层

| 级别 | 方式 | 成本倍率 | 最终性 | 适用场景 |
|------|------|----------|--------|----------|
| L0 | 自报 + 5-10% 抽样 | 0.1x | 即时 | 翻译、摘要、标注 |
| L1 | 冗余 2-of-3 | 2.0x | 数分钟 | 代码审查、数据分析 |
| L2 | TEE 可信执行 | 1.15x | 即时 | 医疗、金融、隐私数据 |
| L3 | zkML + 乐观挑战 | 500x | 数小时 | 高价值、可形式化验证 |
| L4 | 委员会仲裁 | 100x | 数天 | 争议任务、协议升级 |

经济决策公式：`C_verify(level) ≤ V_task × P_fraud`

## 四、设计决策

1. **不替代 MCP/A2A，而是兼容并扩展**：MCP 标准字段 + GSN 扩展字段（gsn_capability、gsn_verify_level、gsn_requires_stake）
2. **声誉不可转让**：资本可以买算力，但不能买信誉和治理权
3. **异步优先**：所有消息基于 JSON-RPC，支持离线后合并
4. **本地优先**：隐私要求支持 LocalOnly / DifferentialPrivacy / TEE / ZK
5. **混合架构**：验证级别由任务价值和欺诈概率自动决策
