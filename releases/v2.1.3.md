## 核心目标

新增 BridgeInsurance 桥接保险池合约，提供质押赔付机制。

## 核心功能

### 保险池机制

- 用户质押 GSP Token 到保险池
- 跨链消息失败时，从保险池赔付损失
- 保费从结算费中提取

### 质押与赔付

```solidity
contract BridgeInsurance {
    function stake(uint256 amount) external;
    function unstake(uint256 amount) external;
    function claimPayout(uint256 messageId) external;
    function depositPremium() external payable;
}
```

### 风险控制

- 保险池总赔付上限
- 单笔赔付限额
- 赔付需要验证（防止欺诈）

## 技术决策

| 决策 | 原因 |
|------|------|
| 质押模式 | 保险池提供者有激励 |
| 赔付验证 | 防止恶意索赔 |
| 保费提取 | 可持续运营 |
