## 核心目标

实现分片过载时的自动翻倍分裂机制，确保百万级 Agent 网络的可扩展性。

## 核心逻辑

```python
# 过载时分裂分片（超过 80% 容量时翻倍）
if meta.counts[sid] > int(meta.max_per_shard * 0.8) and meta.num_shards < 16:
    meta.num_shards *= 2
    meta.counts = {}  # 重置计数，重新分布
    meta.version += 1
```

## 设计要点

| 参数 | 值 | 说明 |
|------|-----|------|
| 触发阈值 | 80% | 超过 max_per_shard 的 80% 时触发 |
| 分裂方式 | 翻倍 | num_shards *= 2 |
| 最大分片数 | 16 | 防止过度分裂 |
| 计数重置 | 是 | 分裂后重新统计 |
| 版本递增 | version += 1 | 记录分片结构变更 |

## 分裂流程

```
Agent 发布到分片 SID
  → 检测 counts[SID] > max_per_shard * 0.8
  → num_shards *= 2（如当前为 4，则变为 8）
  → 清空 counts
  → version += 1
  → 后续 Agent 按新 num_shards 分布
```

## 技术决策

| 决策 | 原因 |
|------|------|
| 80% 阈值 | 留出缓冲，避免刚分裂就过载 |
| 翻倍而非加1 | 指数增长，减少分裂频率 |
| 上限 16 | 防止过度分裂导致查询性能下降 |
| 重置 counts | 分裂后旧计数不再有意义 |
