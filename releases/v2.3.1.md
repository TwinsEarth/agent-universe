## 核心理念

### 从 token 网络到智能体网络

大模型通过参数、数据、算力的 Scaling Law 已实现智能涌现，解决了智能的有无问题。

**智能体宇宙**是在其基础上，实现更多、更大、更强的智能与自我迭代——这是**网络结构的 Scaling Law**，从 token 网络结构向智能体网络结构演进。

### 群众路线

当前基础大模型军备竞赛已达千亿万亿元级门槛，普通人无法参与，智能即将被巨头垄断。

**急需第三方介入**，在闭源阵营与开源阵营之间探索一条普惠大众、全民参与的 AGI 甚至 ASI 之路——**群众路线**。

通过这个全民网络，让底层人民也能参与、贡献、分享这场智能科技革命。（类似于 Linux）

### 结构相变拐点

大模型（参数、数据、算力）的 Scaling Law 已预见单个大模型撞到了 Scaling Law 规模墙。

通过大力出奇迹的收益已经逼近"结构相变拐点"：**Scaling Law 即将失效**，需要从结构上突破。

## 新增模块架构

### 1. swarm/ 群体智能层

**collective.rs** - 群体智能核心
- `AgentNode`: 智能体节点（did, card, stake, reputation, online, success_rate）
- `Swarm`: 群体网络（join, leave, select_by_capability, avg_reputation）
- `AgentNode::score()`: 综合评分 = 信誉 × 成功率 × 质押权重
- `CollectiveDecision`: 群体决策结果

**emergence.rs** - 涌现行为检测
- `EmergenceDetector`: 检测吞吐量增长、延迟下降等涌现信号
- `EmergenceType`: Collaboration / LoadBalancing / FaultTolerance / Evolution
- 基于滑动窗口的历史对比检测

**consensus.rs** - 轻量级共识
- `LightweightConsensus`: 不追求 PoW 安全性，追求快速低成本共识
- `Proposal` / `Vote` / `ConsensusResult`
- 基于质押权重的投票，quorum 机制

### 2. economy/ 信誉经济系统

**reputation.rs** - 信誉分系统
- `ReputationSystem`: 信誉 = 贡献 × 成功率 × 时间衰减
- 支持成功/失败记录、时间衰减、排行榜
- `ReputationRecord`: agent_did, score, tasks_completed, total_value

**contribution.rs** - 贡献证明
- `ContributionProof`: 智能体为网络做了多少贡献
- `ContributionType`: TaskCompletion / ComputeProvided / StorageProvided / Verification / KnowledgeShare / Onboarding
- 每种类型有不同权重（Onboarding 权重最高 = 15）

**pricing.rs** - 任务定价
- `TaskPricing`: 基于供需、难度、紧急程度的动态定价
- `DifficultyLevel`: Trivial(0.5x) → Expert(8.0x)
- `UrgencyLevel`: Low(0.8x) → Critical(2.5x)
- `with_supply_demand()`: 工人不足价格上涨，工人过剩价格下降

### 3. scheduler/ 任务调度器

**router.rs** - 任务路由
- `TaskRouter`: 根据能力、信誉、负载、延迟选择最佳执行者
- `RouteScore`: agent_did, score, estimated_latency_ms, estimated_cost
- 负载惩罚 + 延迟惩罚的评分公式

**load_balancer.rs** - 负载均衡
- `LoadBalancer`: 三种策略
- `BalanceStrategy`: RoundRobin / LeastConnections / LeastResponseTime
- `NodeLoad`: active_tasks, total_tasks, capacity
- `average_utilization()`: 平均利用率

### 4. topology/ 网络拓扑

**neighbor.rs** - 邻居管理
- `NeighborManager`: Kademlia 风格的 k-bucket 邻居管理
- `Neighbor`: did, address, latency_ms, last_seen, failed_pings
- `nearest_neighbors()`: 按延迟排序返回最近邻居
- `remove_unresponsive()`: 移除无响应节点

**graph.rs** - 拓扑图
- `TopologyGraph`: 表示智能体网络的连接关系
- BFS 最短路径计算
- `avg_degree()`: 平均度数
- `density()`: 网络密度
- `shortest_path()`: BFS 最短路径长度

### 5. proof/ 贡献证明

**poc.rs** - Proof of Contribution
- `ProofOfContribution`: 不同于 PoW 的计算浪费，PoC 证明实际有用贡献
- `ContributionRecord`: agent_did, task_id, value, hash, verifiers
- `verify_contribution()`: 多方验证机制，min_verifications 阈值
- `total_contributions()`: 统计智能体总贡献值
