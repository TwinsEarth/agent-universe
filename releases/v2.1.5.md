## 核心目标

提取 CrossChainMessageBase 抽象基合约，消除 ReputationBridge 和 SettlementBridge 的重复代码。

## 重构内容

### 问题

在 v2.1.0-v2.1.4 中，ReputationBridge 和 SettlementBridge 都实现了：
- 跨链消息 ID 生成
- 防重放检查
- 消息发送/接收框架
- 错误处理

这些逻辑重复，维护困难。

### 解决方案

提取 `CrossChainMessageBase` 抽象基合约：

```solidity
aabstract contract CrossChainMessageBase {
    mapping(bytes32 => bool) public processedMessages;
    
    function _sendMessage(uint256 destChain, bytes memory payload) internal virtual;
    
    function _receiveMessage(bytes32 messageId, bytes memory payload) internal virtual {
        require(!processedMessages[messageId], "Already processed");
        processedMessages[messageId] = true;
        _processMessage(payload);
    }
    
    function _processMessage(bytes memory payload) internal virtual;
}
```

### 继承关系

```
CrossChainMessageBase
├── ReputationBridge
└── SettlementBridge
```

## 收益

- 消除重复代码
- 统一防重放逻辑
- 新增桥接合约只需实现 `_processMessage()`
