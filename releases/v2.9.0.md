# v2.9.0 — 大版本「桌面工作台」升级：默认工作区、过程展示分级、后台任务、Office 预览、模型提供商、终端、Subagent / 团队、插件管理

深度参考 **DeepSeek Harness 桌面版**（Electron），把此前的极简 Tauri 2 演示客户端升级为真正的
「工作台」。**继续用 Tauri 2，不迁移 Electron**——核心是 Rust daemon，Tauri 管理 sidecar
天然契合；Harness 仅作功能与产品形态参考。

## 产品形态（对齐 Harness）

- **默认工作区**：新用户无需选择文件夹，自动生成 `~/.agent-universe/workspaces/default`
  （含 agents/tasks/files/output 子目录）。
- **过程展示分级**：results（只看结果）/ steps（关键步骤）/ full（完整过程）。
- **托盘常驻 + 单实例**：关闭窗口=隐藏到后台，托盘菜单显示/退出；多开时聚焦已有窗口。
- **后台任务**：长任务不阻塞，前端每 4s 轮询任务/智能体状态。
- **模型提供商统一入口**：配置集中存 `~/.agent-universe/config.json`。
- **daemon 托管**：桌面端负责查找、启动、健康检查、停止、重启 gsn-daemon；
  仅绑定 loopback（`127.0.0.1`），不暴露局域网。

## 后端列表能力增强（工作台必需）

此前 `GET /api/v1/tasks` 只返回 `{task_count, settled_count}`（注释明写「AgentMarket 未暴露迭代器」），
`GET /api/v1/agents` 无参返回统计。工作台需要真实列表，通过 **`?all=1`** 暴露（不破坏无参统计语义）：

- `MarketCommand` 新增 `ListAllAgents` / `ListAllTasks`；
- 市场新增 `list_all_agents()`（按 agent_id 排序）、`list_all_tasks()`（按 created_at 倒序、再 task_id）；
- REST GET 加集合分支，返回 `{count, agents}` / `{count, tasks}`。

## 客户端构建 pipeline（v2.9.0 大版本重建一次）

- `client-build.yml`：桌面三平台改为构建 **desktop 工作台**（`Workbench` job，DMG/MSI/NSIS/deb/AppImage）；
  Android 仍由 client 工程产出（desktop 暂无移动端配置）。
- `ci.yml`：新增 `workbench-check` job（Ubuntu runner 安装 Tauri 系统依赖后 `cargo check` + clippy）。
- 补齐 desktop 的 capabilities、图标（icns/ico）、tokio 依赖等构建必需项。

## 边界说明（不夸大）

- **LLM 仍为 mock**：核心当前默认 mock，真实 HTTP provider 注入为后续版本；模型提供商页的
  Key/配置已可持久化，但不代表当前后端会真实发起调用。
- **插件为实验开关**：开启开关只写入 feature_flags，不等于对应能力已实现可用。
- **沙箱执行依赖可执行后端**：在默认 `NullExecutor` 平台（无隔离原语）会提示「需配置可执行后端」；
  Windows 上 Job Object 后端可用，Linux/macOS 进程后端按能力声明被拒绝。
- **实时性为轮询**：daemon 暂无真正应用层事件流，任务/智能体采用 4s 轮询；沙箱 exec 为同步返回。
- QA 委员集合仍可由请求体提供；本轮不在此处变更，委员授权门槛（成员来自服务端状态）留待后续版本。
- v2.8.8（七模块）按用户指示跳过；谱系中如实标注。
