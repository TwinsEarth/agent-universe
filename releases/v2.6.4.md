# v2.6.4 — 共识 / 身份签名加固（GAP §3.3 / §3.6 / §4.2–§4.9）

发布日期：2026-09-28
对应 gsn-core：0.2.64

## 主题

按 GAP-ANALYSIS 审计，本版本集中加固**共识委员会算术、身份/规范签名、时钟与弱公钥**九处缺陷。跨语言签名向量（上游 `did:aip:34750f98…`）逐字节命中保持不变。

## 修复清单

| GAP | 缺陷 | 处理 |
| --- | --- | --- |
| §3.3 | BFT 委员会 `min_n = 3f+1` / `quorum` 普通乘法可溢出 | `checked_mul(3)+checked_add(1)`，溢出即 Err；`quorum()` checked，溢出安全降级；`tally()` 复用 `self.quorum()` |
| §3.6 | 贡献验证任何人可重复投票凑数、贡献者可自验、无签名、计数溢出 | 新增 `verify_contribution_signed`（验签覆盖 `hash||verifier_did`、禁自验、去重、饱和计数）；旧 `verify_contribution` 同步加禁自验+去重+饱和（标注仅本地受信） |
| §4.2/§4.3 | `canonical_payload` 对不可序列化对象静默签空字节；未递归剥离 `signature` 嵌套 | 整体重写：`canonical_object` 要求根为对象（否则 `RootNotObject`）；`strip_signatures` 任意深度递归剥离；`sign_hex/verify_hex/canonical_payload` 全改 `Result`；4 个单测 |
| §4.4 | JS `Object.keys().sort()` 按 UTF-16 码元序，与 Rust BTreeMap / Python 码点序在 astral 平面分歧 | JS 改用显式 Unicode 码点比较器；新增 astral 键序回归向量与 `conformance/vectors.json` 钉住 |
| §4.5 | 收到的规范字节被丢弃、签名覆盖的是重序列化结果 | 引入 `PROTOCOL_VERSION = "nau/1"` 契约：签名覆盖规范形式，改规范字节必须 bump 版本；重放由 nonce+时间戳+`verify_fresh` 承担 |
| §4.6 | 接受弱公钥（全零 / 全相同 / 长度错） | 新增 `identity::is_weak_pubkey`（长度≠32、全零、全 0xFF、32 字节全相同均拒）；保留 8 字节指纹兼容上游 |
| §4.8 | 八处 `SystemTime::now().duration_since(..).unwrap()`，时钟早于 1970 即 panic | 新建 `aca::clock` 端口（`SystemClock` 饱和不 panic + `ManualClock` 确定性）；aca 下全部 8 处改走 `clock::now_secs()` |
| §4.9 | 公开摘要用 `==` 非常量时间比较 | 文档明确「比较公开摘要不构成安全边界」，秘密比较必须走常量时间 |

## 验证

- Rust 全量 **146** 单元测试 + 全部集成测试 **0 failed / 0 ignored**（新增 aca::clock 2、aca::crypto 4、identity weak_pubkey 2、qa_committee 认证 7）。
- JS SDK **20** passed（新增 v2.6.4 码点序 astral 向量用例）。

- 跨语言上游签名向量仍逐字节命中（`did:aip:34750f98…`）。
