# v2.4.1 - Lv1–Lv7 分层拓扑（Layer）

## 一句话概述

v2.4.1 把网络从扁平 P2P 升级为 UDOS 七层分层结构（Lv1 房间级 → Lv7 宇宙级），任意节点扇入有界、总边数亚二次、跨节点路由 ≤7 跳，并提供默认分层、失败回退扁平的路由器。

## 七层语义

| 层级 | 名称 | 量级 |
|---|---|---|
| Lv1 | 房间级 | 几十 |
| Lv2 | 楼栋级 | 数百 |
| Lv3 | 城市级 | 数千 |
| Lv4 | 省级 | 数万 |
| Lv5 | 国家级 | 数十万 |
| Lv6 | 大洲级 | 数百万 |
| Lv7 | 宇宙级 | 全球（根种子） |

## 关键不变量

- 每节点扇入 ≤ fanout（默认 9，对齐 P0b 实测）。
- 总边数 O(N·fanout)，远小于星型/网状的 O(N²)。
- 跨房间路由恒为 7 跳，同房间 1 跳。
- `TopologyRouter` 默认分层，失败自动回退扁平 `TopologyGraph` 并记 `fallback=flat`；旧实现并存不删。

## 验证

- 10,000 节点：扇入 ≤8、边数亚二次、路由 ≤7 跳，测试全绿。
