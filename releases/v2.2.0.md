# v2.2.0 开发日志

## 基本信息

- **版本号**：v2.2.0
- **发布日期**：2026-09-22
- **类型**：大版本（Major Feature Release）
- **Commit**：`03c011ab`

## 核心目标

引入 Rust 核心层 gsn-core，实现真正的对等网络架构：libp2p + DHT + GossipSub + PoCV。

## 新增模块

### gsn-core (Rust crate)

| 模块 | 功能 |
|------|------|
| `net/libp2p_node.rs` | libp2p host、Noise 加密、Yamux 多路复用 |
| `net/dht.rs` | Kademlia DHT 客户端 |
| `net/gossip.rs` | GossipSub 消息广播 |
| `net/transport.rs` | TCP / QUIC / WebRTC 传输 |
| `identity/did.rs` | DID 生成与解析 |
| `identity/keyring.rs` | 平台安全存储抽象 |
| `identity/signer.rs` | Ed25519 签名 |
| `agent/card.rs` | AgentCard 模型 |
| `agent/task.rs` | 任务状态机 |
| `chain/pocv.rs` | PoCV 轻量验证计算 |

### 多模式终端

| 模式 | 资源占用 | 能力 |
|------|----------|------|
| Full | 2GB RAM | DHT 服务端 + 做种 + 验证 |
| Light | 200MB RAM | DHT 客户端 + 任务执行 |
| Mobile | 50MB RAM | 后台同步 + 签名 |
| Browser | WASM | 签名 + 查询 |

### 根种子机制

- Mac mini 作为首个节点
- 无 bootstrap 地址启动
- 第二个节点配置 Mac mini 地址加入
- 网络成熟后 Mac mini 自动降级为普通节点
