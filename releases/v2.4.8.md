# v2.4.8 - DeepSeek 模型适配层（deepseek-recipe）

## 一句话概述

v2.4.8 新增 DeepSeek 模型适配层：精确复刻官方提示词编码、多协议格式互转、token 级编解码与上下文预算管理，让网络中每个智能体在执行推理时可正确对接 DeepSeek 后端。

## 分工定位

- **agent-universe**：解决"智能体如何组网与经济协作"（P2P 网络、身份信任、任务市场、经济结算、链上治理）。
- **deepseek 适配层**：解决"单个智能体如何与模型正确交互"（提示词编码、协议互转、token 预算）。

两者互补：agent-universe 中的每个智能体在执行推理时，可使用本适配层对接 DeepSeek 模型后端。

## 四大子模块

### 1. recipe — 提示词编码配方

- `DeepSeekModel`：`Chat("deepseek-chat")` / `Reasoner("deepseek-reasoner")`，上下文窗口 64K，reasoner 支持思考链。
- `DsMessage` / `DsRole`：system / user / assistant / tool 四角色消息格式，reasoner 模型返回 `reasoning_content`。
- `DsSampling`：temperature ∈ [0,2]、top_p ∈ [0,1]、max_tokens ∈ (0,8192]，`validate()` 校验合法区间。
- `Recipe`：`system_prompt(identity, instruction)` 注入 gsn 身份与任务约束；`build_request()` 组装完整 chat 请求。

### 2. protocol — 多协议格式互转

- gsn 内部消息 ↔ DeepSeek 消息（角色枚举无损转换，未知角色报错）。
- DeepSeek 请求 ↔ OpenAI 兼容请求（采样参数展平往返）。
- `extract_answer()` 提取纯文本；`extract_reasoning()` 提取思考链（reasoner 模型）。

### 3. tokenizer — token 级编解码与上下文预算

- `estimate_tokens()`：ASCII ~4 char/token、CJK ~1.5 char/token 启发式估算（非真 BPE，用于预算控制）。
- `ContextBudget`：输入预算 = 64K − 预留输出 tokens；`fits()` 判断是否超预算；`truncate_history()` 保留 system + 从最新往旧截断。
- 角色开销 ~4 tokens/条消息，对话格式开销 ~3 tokens/请求。

### 4. adapter — 模型适配器（接入异构协商）

- `DeepSeekConfig`：model / base_url / api_key_env / sampling，默认 `https://api.deepseek.com/v1`。
- `DeepSeekClient` trait：便于替换为真实 HTTP 客户端；默认 `MockDeepSeekClient`（CPU 原型不发网络）。
- `DeepSeekAdapter::chat()`：三步流程——validate 采样参数 → 构造请求 + 上下文截断 → 调用客户端 → 提取答案。
- `as_llm_model()`：暴露为 `family="deepseek"` 的 `LlmModel`，直接接入 v2.4.7 的 `Deliberation` 加权投票。
- `propose()`：便捷产出 `Proposal`，供协商会话收集异构提案。

## 与 v2.4.7 的集成

```
Deliberation（v2.4.7）
  ├── LlmModel { family: "gpt", ... }
  ├── LlmModel { family: "claude", ... }
  └── LlmModel { family: "deepseek", ... }  ← v2.4.8 DeepSeekAdapter::as_llm_model()
        │
        └── DeepSeekAdapter::chat()
              ├── Recipe::system_prompt()     // 提示词编码
              ├── Protocol::ds_to_oai()       // 协议互转
              ├── ContextBudget::truncate()   // token 预算
              └── DeepSeekClient::chat()      // 模型调用（Mock / 真实 HTTP）
```

## 验证

- 15 个 deepseek 模块测试全绿（recipe 4 + protocol 4 + tokenizer 3 + adapter 4）。
- 完整 `cargo test --lib`：40 passed / 0 failed。
- 编译零 warning（修复了 E0382 move 错误与未使用变量）。

## 边界声明

- `MockDeepSeekClient` 不发真实 HTTP 请求；真实网络注入通过 `DeepSeekClient` trait 抽象，生产环境实现该 trait 即可。
- token 估算为 ASCII/CJK 启发式，非 DeepSeek 官方 BPE；用于预算控制而非精确计费。
- `reasoning_content` 仅 `deepseek-reasoner` 模型返回；`deepseek-chat` 不产生思考链。
- 未处理流式响应（`stream: false`）；流式支持留待后续版本。
