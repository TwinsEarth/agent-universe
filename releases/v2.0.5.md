## 核心目标

新增 `get_shard_stats()` 查询接口，支持运维监控和分片健康检查。

## 新增接口

```python
async def get_shard_stats(self, cap: str) -> dict[int, int]:
    """返回各分片当前计数。"""
    meta_key = f"/aip/cap/{cap}/r/GLOBAL/meta"
    data = await self.dht.get(meta_key)
    if not data:
        return {}
    meta = ShardMetadata.from_bytes(data)
    return dict(meta.counts)
```

## 使用场景

1. **分片负载监控**：运维人员查看各分片 Agent 分布
2. **分裂预警**：检测到某分片计数接近 `max_per_shard`
3. **容量规划**：基于历史计数趋势预测扩容需求
