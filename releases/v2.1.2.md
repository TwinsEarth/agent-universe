## 核心目标

新增 CrossChainRouter 路由层，实现速率限制和熔断器模式。

## 新增功能

### 速率限制（Rate Limiting）

- 每个目标链的消息发送频率限制
- 防止跨链消息洪泛
- 基于时间窗口的滑动窗口算法

### 熔断器（Circuit Breaker）

- 当跨链消息失败率超过阈值时自动熔断
- 熔断状态：CLOSED → OPEN → HALF_OPEN
- 半开状态下探测性发送，成功后恢复正常

## 合约接口

```solidity
contract CrossChainRouter {
    function route(uint256 destChain, bytes calldata message) external;
    function setRateLimit(uint256 chain, uint256 maxPerWindow, uint256 window) external;
    function setCircuitBreaker(uint256 chain, uint256 threshold, uint256 cooldown) external;
}
```

## 技术决策

| 决策 | 原因 |
|------|------|
| 滑动窗口 | 精确的速率限制 |
| 三态熔断器 | 防止雪崩效应 |
| 链级独立配置 | 不同链的稳定性不同 |
