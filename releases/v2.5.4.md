# Agent Universe v2.5.4 — NAT 穿透增强

**发布日期**: 2026-09-26
**代号**: Traversal
**前置版本**: v2.5.3 (Mesh)

## 核心目标

v2.5.3 的 mesh 模块在单机和局域网内工作正常，但跨 NAT 场景下节点无法直连。v2.5.4 在真实 libp2p 层（而非模拟 nat 模块）加入 Circuit Relay v2、AutoNAT、DCUtR 打洞和 Ping 保活，使分属不同 NAT 的节点可通过公共中继跨网互连。

## 新增能力

### 1. Circuit Relay v2 客户端

- 类型: `libp2p::relay::client::Behaviour`
- 节点在 NAT 后可向公共中继申请 reservation
- 其他节点通过中继地址（`/p2p/<relay>/p2p-circuit/p2p/<target>`）dial 到本机
- SwarmBuilder 链新增 `.with_relay_client(noise, yamux)`

### 2. AutoNAT 自动 NAT 检测

- 类型: `libp2p::autonat::Behaviour`
- 主动向已连接节点发起 dial-back 探测
- 三态输出: `public` / `private_nat` / `unknown`
- 配置: retry_interval 10s, refresh_interval 30s, confidence_max 1

### 3. DCUtR TCP 打洞

- 类型: `libp2p::dcutr::Behaviour`
- 直连失败后自动协调双方同时向对方发起连接
- 打洞成功后升级为直连，无需中继转发

### 4. Ping 连接保活

- 类型: `libp2p::ping::Behaviour`
- 15 秒间隔保持 NAT 映射不过期
- 同时测量连接 RTT

### 5. 公共网络引导

- 新增 `P2pPeer::bootstrap_public_network()`
- 自动 dial 4 个官方 `bootstrap.libp2p.io` 节点（同时是 relay 中继）
- 新增 HTTP API:
  - `POST /api/v1/network/bootstrap-public` — 发起公共网络连接
  - `GET /api/v1/network/nat` — 查询 NAT 检测状态

## API 变更

| 端点 | 方法 | 说明 |
|---|---|---|
| `/api/v1/network/bootstrap-public` | POST | 连接公共 libp2p bootstrap/relay 网络 |
| `/api/v1/network/nat` | GET | 获取 AutoNAT 检测的 NAT 状态 |
| `/api/v1/network/info` | GET | PeerInfo 新增 `nat_status` 字段 |

## 边界声明

- 公共中继连接需要节点出站能访问 bootstrap.libp2p.io（TCP 4001/443）
- 出站严格受限的网络环境（仅 DNS）无法建立中继连接
- DCUtR 打洞成功率取决于 NAT 类型；对称型 NAT 打洞成功率低，仍需中继
- 原模拟 nat 模块（`src/nat/`）保留，mesh.rs 仍引用其数据结构；真实穿透由 libp2p 层承载
