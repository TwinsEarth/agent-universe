# v2.7.6 — Agent Sandbox 核心架构（大版本重构第一步）

智能体沙箱（Agent Sandbox）系统的起点版本。本版本只做**核心架构与类型定义**，不引入具体执行实现——先把沙箱在 Agent Infra 中的位置、边界、生命周期、安全默认定清楚。

## 背景

Agent 进入生产后，基础设施从"让 AI 思考"（推理时延/吞吐）转向"让 AI 行动"（执行）。沙箱从隔离不可信代码的安全机制，演化为承载 Agent 执行的底座——为进程、文件、网络、存储、权限设边界，管理完整生命周期。

## 新增模块（gsn-core/src/sandbox/）

1. **error.rs**：统一错误类型
   - `EnvBlocked`（环境不具备，应降级）、`IsolationViolation`（安全事故，应终止审计）、`ExecFailed`、`ResourceLimitExceeded`、`InvalidConfig`、`InvalidLifecycle`、`NotFound`、`NetworkDenied`、`Internal`
   - 提供 `is_security()` / `is_env_blocked()` / `is_retryable()` 分类。

2. **config.rs**：配置与策略
   - `IsolationLevel`（Process / ContainerSharedKernel / MicroVM，带 strength）
   - `ResourceLimits`（CPU/内存/磁盘/进程数/句柄/超时，全为硬上限）
   - `NetworkPolicy`（默认全拒绝，出站白名单）
   - `FilesystemPolicy`（只读根，仅独立临时目录可写）
   - `SandboxConfig` + `validate()`（拒绝零配额、空放行、逃逸路径）。

3. **state.rs**：生命周期状态机
   - 状态：Pending → Creating → Starting → Running ⇄ Paused → Stopping → Stopped；任意非终态 → Failed
   - `transition(action)` 校验合法迁移，非法迁移返回原因；
   - 关键边界：只管沙箱自身运行状态，业务状态由上层记录。

4. **identity.rs**：身份
   - `SandboxIdentity`（临时，生命周期内有效）、`AgentIdentity`（长期，密钥不进沙箱）
   - `ExecutionToken`（短时令牌：最小权限 + TTL + 可吊销，`authorize()` 校验）。

5. **docker.rs / firecracker.rs**：更新为显式环境探测——无 daemon / 无 KVM 即 `EnvBlocked`，不静默冒充。
