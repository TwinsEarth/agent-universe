## 核心目标

修复 `shard_of` 函数的哈希分布不均匀问题。

## 问题描述

在 v2.0.0-v2.0.2 中，`shard_of(did, num_shards)` 使用 `int(hashlib.sha256(did.encode()).hexdigest(), 16) % num_shards`。

问题：当 `num_shards` 不是 2 的幂时，取模运算会导致分布不均匀——低位分片概率略高。

## 修复方案

```python
def shard_of(did: str, num_shards: int) -> int:
    h = int(hashlib.sha256(did.encode()).hexdigest(), 16)
    return h % num_shards
```

实际上 SHA256 的输出在大数上是均匀的，取模不均匀只在 `num_shards` 接近 `2^256` 时才显著。对于 `num_shards <= 16`，分布已经足够均匀。

真正的修复是：
- 验证 100 个 DID 在 1/2/4/8 分片下的分布均匀性
- 添加分布测试用例

## 测试

```python
def test_shard_of_distribution():
    ids = [f"did:aip:0x{i}" for i in range(100)]
    for n in [1, 2, 4, 8]:
        buckets = {}
        for did in ids:
            sid = shard_of(did, n)
            buckets[sid] = buckets.get(sid, 0) + 1
        assert len(buckets) == n
```
