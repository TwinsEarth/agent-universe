# v2.4.0 - CPU 治理轻量化（Govern）

## 一句话概述

v2.4.0 把市场结算主路径从「每次全表扫描」改为 O(1) 增量维护，并抽象统一的任务沙箱接口（Docker 默认、Firecracker microVM 强隔离），让治理开销可测、单机密度可扩展。

## 结算守恒 O(1)

- `SettlementEngine` 新增 `balance_sum` / `total_paid_acc` 增量字段，随 deposit / settle / slash 即时增减。
- `conservation_check()` 改 O(1)，不再遍历全表；新增 `audit_full_scan()` 作为运维对账入口。
- 不变量逐位保持：`balance_sum = total_budget - total_slashed`，`total_paid ≤ total_budget`。

## 沙箱 trait

- 新增 `Sandbox` trait + `IsolationLevel`（DockerSharedKernel / MicroVM）。
- `DockerSandbox` 默认后端；`FirecrackerSandbox` 完整配置（vmlinux / rootfs / vCPU / MMDS）。
- 无 `/dev/kvm` 时 Firecracker 显式返回 `EnvBlocked`，不静默降级冒充。

## 验证

- 新增增量与全量对账一致性测试；全量 cargo 测试通过。
