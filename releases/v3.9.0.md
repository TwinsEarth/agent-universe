# v3.9.0 — 比特币/以太坊 Agent 经济体（1/9）：结算路由 PaymentRouter（纯确定性整数选路，闪电 L402 / EVM x402 / BTC RGB·HTLC 三轨，只决策不动钱，缺轨 fail-closed）

## 一、交付了什么

v3.8.x 资源市场完成了「闲置资源」的内部记账/撮合/定价/结算守恒，但其记账单位
Credits 不挂法币、不挂链。v3.9.x 起进入**比特币/以太坊 Agent 经济体**：把资源市场
接到真实数字货币基础设施，形成三层货币体系——价值锚定（比特币主链 RGB/HTLC）、
可编程结算（以太坊 L2 x402 + 稳定币/ERC-4337）、即时支付（比特币闪电 L402）。

v3.9.0 作为 1/9，交付这一体系的第一块、也是最底层的一块：**结算路由**。给定一笔待
结算金额（内部整数 micro）、时延/周期要求（即时/常规/跨周期）、条件（是否需要智能
合约、是否需要 DeFi 组合）以及本节点实际可用轨道，确定性选出**唯一**一条结算轨道并
给出可审计理由。

新增目录与文件 `gsn-core/src/economy/payment/`：
- `router.rs`：选路内核；零浮点、零 syscall、零 unsafe、无 panic 路径，金额 `u128`
  micro，全部为整数比较。
- `mod.rs`：系统插件 `com.twinsearth.sys.payment-router` 常量、类型化错误、诚实
  `payment_router_status` 只读负载、T0 handler 注册。

1. **三条结算轨道 `PaymentTrack`**：
   - `lightning_l402`：比特币闪电网络 L402/x402-LN，近乎即时、极低费，适合金额很小且
     要求即时的高频微支付；
   - `evm_x402`：以太坊 L2 x402 + 稳定币/ERC-4337，可编程条件支付、DeFi 组合与日常
     中等额结算的默认轨道；
   - `btc_rgb_htlc`：比特币主链 RGB/Taproot 或 HTLC 原子交换，大额或跨周期最终结算的
     价值锚定轨道（`is_finality()==true`）。

2. **确定性选路优先级（自上而下短路，`PaymentRouter::route`）**：
   1) 需要 DeFi 组合 → 仅 EVM 可表达 → `evm_x402`（`DefiComboRequiresEvm`）；
   2) 需要智能合约条件 → 仅 EVM 可表达 → `evm_x402`（`SmartContractRequiresEvm`，
      可编程性优先于大额/跨周期的主链最终性偏好）；
   3) `amount >= large_floor`（默认 100_000_000 micro=100 credits）或 `cross_epoch`
      且无合约要求 → `btc_rgb_htlc`（`LargeOrCrossEpochFinalSettlement`）；
   4) `instant` 且 `amount <= instant_cap`（默认 10_000 micro=0.01 credit）→
      `lightning_l402`（`InstantMicroPayment`）；
   5) 其余常规区间 → `evm_x402` 稳定币默认（`StablecoinDefaultMidRange`）。
   阈值是宿主受控策略常量（`RoutingPolicy`），内核不宣称其法币/币价含义；
   `RoutingPolicy::validated` 要求两阈值为正且即时上限严格小于最终下限，否则
   `RoutingPolicyInvalid`。

3. **fail-closed，不静默降级**：决策所需轨道在本节点不可用时，返回
   `RouteTrackUnavailable{required}` 具名拒绝，绝不悄悄改走别的轨道——把需要最终结算的
   大额改成 L2、或把需要即时的微支付改上主链，都会改变费用/最终性/信任假设，必须由
   调用方显式处理。`RoutingInput::new` 另对零金额（`NonPositiveAmount`）、无任何可用
   轨道（`NoAvailableTrack`）、`defi=true 且 smart_contract=false` 自相矛盾
   （`DefiWithoutSmartContract`）做构造期拒绝。

4. **只决策，不动钱**：本版本不持有/不接触私钥，不签名、不广播、不划转、不托管、不
   兑换，不调用闪电节点/EVM RPC/RGB，纯函数；经 T0 native 系统插件只注册只读
   `payment_router_status` 与选路内核，`provided` 诚实标注三类节点连接均 false，
   `enforceable` 中 fund_movement/key_holding/transaction_signing/transaction_broadcast/
   onchain_anchor_write/currency_exchange 全部 false。本版本仅声明只读能力
   `pay:route:read`；`pay:execute`/`wallet:sign`/`chain:anchor:write` 仅登记为后续
   版本保留，不实际授予。系统插件集由 6 个增至 7 个
   （identity/net/storage/chain/ausec/resource-market/payment-router）。

版本映射：npm `@twinsearth/agent-universe` 3.9.0 ↔ Rust `gsn-core`/`gsn-daemon` 0.3.90。

## 三、诚实边界（做不到的具名拒绝）

- 本版本是**纯决策内核**，没有任何资金面：不持私钥、不签名、不广播、不划转、不托管、
  不兑换、不连闪电/EVM/BTC 节点、不持久化；`status` 中三类节点连接与全部资金/密钥/
  链上写位均诚实为 false。
- 宿主签名服务与私钥隔离（沙盒只见公钥、具名拒签）在 **v3.9.1**；EVM x402(USDC) 在
  **v3.9.2**；闪电 L402 适配在 **v3.9.3**；ERC-8004 三注册表在 **v3.9.4**；
  ERC-4337 Paymaster 赞助在 **v3.9.5**；BTC HTLC/RGB 纯校验在 **v3.9.6**；链上锚定/
  跨链桥风控在 **v3.9.7**；ZK 支付意图/OWS/合规接口在 **v3.9.8**。在对应版本落地前
  这些方法不注册（NotFound），不伪造可用。
- 默认阈值（0.01 / 100 credits）是整数策略分界，**不构成对法币或任何币价的承诺**，
  可由宿主经 `RoutingPolicy` 覆盖（须通过 `validated`）。
- 文档中涉及的外部协议采用量/性能数字（x402 交易量、BlackRock 模型储蓄/支付占比、
  ERC-8004 采用量、A402 性能等）均为**第三方报道口径，非本仓复测**，内核不内置这些
  数字作为事实。
