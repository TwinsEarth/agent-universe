# v3.7.2 — AUSec 镜像按需加载（2/9）：BlockStore 本地元数据 + 按需取块 + 只读共享（patch）

## 一、交付了什么
- `gsn-core/src/ausec/blockstore.rs`：
  - `BlockStore`：构造只持有清单 + 源（**零取块**，本地仅存元数据）；`get_chunk` 缺块即取、命中复用；`assemble_image` 按需拼全镜像。
  - `BlockSource` 契约 + `LocalDirBlockSource`（**真实**内容寻址本地目录，std::fs）+ `UdosRemoteBlockSource`（**具名远端，v3.7.2 fetch 一律 RemoteNotImplemented，不伪造跨网传输**）。
  - `SharedChunkCache`：按 sha256 内容地址去重，跨 store/跨镜像返回同一 `Arc<[u8]>`（只读共享，为 3.7.4 共享额度铺垫）。
  - 取回字节**强制过 v3.7.1 `verify_chunk`（sha256）**，坏源字节绝不入缓存（rejected_corrupt 计数）。
  - `BlockStats{hits,misses,fetches,rejected_corrupt}` 证明懒加载/命中复用。
- `ausec/mod.rs` 接线导出。
