# v2.4.2 - 个体内部记忆 + 群体外部共享记忆（Memory）

## 一句话概述

v2.4.2 新增 Memory Sharing 模块：个体智能体维护本地内部记忆库（成功/失败轨迹、学到的模式），群体维护外部共享记忆库（按发布者信誉加权检索最佳策略）。

## 内部记忆 `AgentMemory`

- 记录成功/失败案例，维护 task_key → 最佳策略模式。
- 提供 `recall()` 召回与 `hit_rate()` 命中率。

## 外部记忆 `SwarmMemory`

- 任意 Agent 可发布经验（含信誉权重）。
- `best_strategy()` 按权重选最佳成功策略；`known_failures()` 统计失败坑。

## 验证

- 个体记录/召回、群体加权选策略测试全绿。
