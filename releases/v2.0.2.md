## 核心目标

引入 predictor 七模块包，为分片容量预测和 Agent 调度提供算法支持。

## 新增模块

### predictor 七模块包

| 模块 | 功能 |
|------|------|
| `trend.py` | 趋势检测：线性回归、移动平均 |
| `changepoint.py` | 变点检测：识别分片负载突变 |
| `seasonal.py` | 季节分解：识别周期性负载模式 |
| `residual.py` | 残差分析：检测异常值 |
| `confidence.py` | 置信区间：预测不确定性量化 |
| `fusion.py` | 融合预测：多模型加权融合 |
| `report.py` | 报告生成：预测结果可视化输出 |

## 技术决策

| 决策 | 原因 |
|------|------|
| 纯 Python 实现 | 无外部依赖，易于测试 |
| 模块化设计 | 各模块可独立替换 |
| 加权融合 | 简单模型比单一模型更稳健 |

## 测试

- 趋势检测：线性数据预测精度
- 变点检测：突变点识别准确率
- 季节分解：周期数据还原
- 融合预测：多模型一致性
