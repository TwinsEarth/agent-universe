# Release v2.5.6 — 历史 Bug 回归套件（Regression Suite）

**发布日期**：2026-09-27
**主题**：把 v1.0.0 ~ v2.5.5 开发过程中踩过、修过的全部 bug / 遗漏 / 注意事项固化为每次必跑的回归测试，杜绝同类问题反复出现。

## 背景

Agent Universe 从 v1.0.0 到 v2.5.5 经历了 P2P 网络、身份信任、任务市场、经济结算、跨平台客户端、多模型适配、relay/NAT 穿透等大量模块。期间多次出现"同一个坑反复踩""bump 版本丢三落四""修了的 bug 又复发"。本版本不新增业务功能，而是建立**长效回归机制**：每一个历史问题都对应一条自动化用例，每次发版、每次改动都强制全量跑。

## 新增

### 1. JS / SDK 历史 Bug 回归套件 `test/regression.js`（14 条）

| 分组 | 覆盖内容 |
| --- | --- |
| **A. 版本一致性（4 条）** | 四个 `package.json`、`gsn-core/Cargo.toml`、两个 `Cargo.lock`、`pyproject.toml` / js 运行时 / `ci.yml` 版本必须全部一致（npm 线与 Rust 线 `0.2.(Y*10+Z)` 自动换算） |
| **B. 编译 & CI 守卫（4 条）** | peer.rs `subscribe()` 不再自引用 `IdentTopic::new(t)`；release.yml 含 `permissions: contents: write`；glob 容错 `nullglob`；publish.yml 含 `npm publish` 闭环 |
| **C. 市场重复防护（4 条）** | 重复注册被拒、重复结算返回 `already_paid`、负金额 / 空 goal / 非正预算抛错、未注册投标 / 无投标匹配抛错 |
| **D. 资金守恒（2 条）** | 无罚没时系统总余额 == 总充值；罚没后系统总余额 == 总充值 − 罚没 |

### 2. Rust 网络层回归 `gsn-core/tests/regression_net.rs`

- 用随机临时身份（`Keypair::generate_ed25519`）构造节点，`subscribe()` 后 `publish()` 不 panic。
- 无 mesh peer 时 GossipSub 返回 `InsufficientPeers` 判定为正常，其他错误才失败。

### 3. 一键全量脚本

- `test/run-all.sh`（Linux / macOS）、`test/run-all.ps1`（Windows）：依次跑 JS SDK 单测、历史 bug 回归、Rust 全量测试。
- `test/README.md`：完整用例索引、已知"做不通 / 易踩坑"清单、维护规则。

### 4. CI 接入

- `.github/workflows/ci.yml` 的 JS job 新增 **Run historical-bug regression suite**（`node test/regression.js`）步骤，每次 push / PR 自动执行。

## 修复

- **`scripts/bump-version.sh` 自身 5 处缺陷**（此前脚本无法正确一键 bump）：
  1. `_$V_` 中 bash 把 `$V_` 当成变量名 → 改为 `${V}`；
  2. 版本正则里的 `+` 在 sed 默认 BRE 下不被支持 → 转义为 `\+`；
  3. gsn-core Cargo 版本 sed 误拼成四段 `0.2.X.Y.Z` → 修正为 `0\.2\.[0-9]\+`；
  4. ci.yml 的 sed 规则多余空格、`.` 未转义 → 修正；
  5. 新增 client/desktop `lib.rs` 头注释与 Identify `/gsn/0.2.YZ` 两条规则。
- 同步把版本号全仓 bump 到 **npm 2.5.6 / gsn-core 0.2.56**。

## 后续规则（长期生效）

1. **修复任何新 bug，先在 `test/`（或对应语言 tests 目录）追加一条能复现的用例**，确认它在修复前失败、修复后通过，再提交。
2. 新增功能时，新的版本声明点 / 配置点必须同步登记进 `docs/version-checklist.md`，并在 `scripts/bump-version.sh` 加对应规则。
3. 用例编号只增不复用；每次发版必须全量回归通过，否则不得发布。

## 兼容性

- 完全向后兼容 v2.5.5；本版本不改变任何运行时业务行为与公开 API，仅新增测试与发布工程能力。
