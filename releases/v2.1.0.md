# v2.1.0 开发日志

## 基本信息

- **版本号**：v2.1.0
- **发布日期**：2026-09-22
- **类型**：大版本（Major Feature Release）
- **Commit**：`cf1c47be`

## 核心目标

引入多链桥接层，基于 CCIP（Chainlink）和 LayerZero 实现跨链信誉同步和结算分账。

## 新增合约

### 1. ReputationBridge

- 跨链信誉同步合约
- 源链发送信誉更新消息，目标链接收并验证
- 使用 CCIP/LayerZero 跨链消息协议

### 2. SettlementBridge

- 跨链结算分账合约
- 支持多链结算、分账、退款
- 与 PoCV 验证结果联动

### 3. CrossChainRouter

- 跨链路由层
- 管理多链连接、消息路由、失败重试

### 4. BridgeInsurance

- 桥接保险池
- 质押赔付机制

### 5. GovernorToken

- ERC20 + 信誉注册表
- 治理代币与信誉绑定

## 技术栈

- Foundry（Forge）
- Solidity ^0.8.20
- OpenZeppelin Contracts
- Chainlink CCIP
- LayerZero
