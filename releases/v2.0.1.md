## 核心目标

在 v2.0.0 的多级分片基础上，增加跨区域桥接、动态区域支持、容量预测和分片合并保护。

## 新增功能

### 1. 区域桥接（Region Bridge）

- 跨区域 Agent 发现：当本区域分片无结果时，桥接到其他区域查询
- 桥接延迟：异步并发查询多区域，先到先返回

### 2. 动态区域（Dynamic Region）

- 运行时可新增区域分片
- 新区域自动从 GLOBAL 区域同步初始 AgentCard 索引
- 区域下线时自动迁移 Agent 到最近区域

### 3. 容量预测（Capacity Prediction）

- 基于历史计数预测分片负载趋势
- 预测指标：增长速率、预计到达阈值时间
- 提前触发分裂预警

### 4. 合并安全期（Merge Safety Period）

- 分片合并后设置安全期（默认 60 秒）
- 安全期内不重复合并，防止抖动
- 安全期内新 Agent 仍可正常发布

## 技术决策

| 决策 | 原因 |
|------|------|
| 异步桥接 | 避免跨区域查询阻塞主流程 |
| 安全期 | 防止分片频繁分裂/合并导致索引不稳定 |
| 历史计数 | 简单线性预测，无需 ML 模型 |
