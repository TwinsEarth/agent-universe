# v2.1.9 macOS 全对等网络升级

## 版本信息
- **版本**: v2.1.9
- **类型**: 🔵 小版本
- **核心主题**: 全对等网络架构

## 核心目标
实现根种子节点、多模式终端、DHT 自愈、CRDT 同步、纠删码冗余。

## 新增模块

### 1. 根种子节点
- `net/root_seed.rs` - RootSeedConfig、SeedMode
- 引导期自动降级（Root → Bootstrap → Normal）
- 降级阈值: 1000 活跃节点

### 2. 多模式终端
- `mode/mod.rs` - NodeMode、ModeController
- 五种模式: Archive / Full / Light / Edge / Browser
- 模式切换不改变 DID，信誉保留

### 3. CRDT 状态同步
- `crdt/mod.rs` - VersionVector
- 双向合并收敛
- 离线优先，恢复自动同步

### 4. 纠删码冗余
- `erasure/mod.rs` - ErasureCoder
- Reed-Solomon 编码
- 4 数据分片 + 2 校验分片
- 丢失 2 片仍可恢复

## 技术决策

| 决策项 | 选择 | 原因 |
|--------|------|------|
| 网络架构 | 全对等 | 无单点故障，根种子可离线 |
| 状态同步 | CRDT | 离线优先，无需中央服务器 |
| 数据冗余 | 纠删码 | 比副本更高效 |
| 节点模式 | 五档 | 适配不同硬件资源 |
