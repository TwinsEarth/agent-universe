# v2.7.0 — 全平台客户端大版本

自 v2.3.5 首次引入 Tauri 桌面壳以来，这是**第一次**随版本发布重建并交付全平台客户端。按既定节奏，此后每 9 个小版本后的大版本才再构建一次客户端。

## 本版

- **版本号统一到 2.7.0**（npm ↔ gsn-core `0.2.70`），覆盖 `desktop/`（Tauri 桌面壳）与 `client/`（跨端壳，含 `ios/`、`platforms/`、`src-tauri/`）的 Cargo.toml、pyproject、aip-sdk 版本声明。
- 客户端矩阵由 CI 在对应 runner 上构建并随 Release 附上：
  - macOS（aarch64-apple-darwin）
  - Windows（x86_64-pc-windows-msvc）
  - Linux（x86_64-unknown-linux-gnu）
  - 守护进程 tarball 同时提供 `gsn-daemon-*` 各平台二进制。
- 客户端内嵌 SDK `@twinsearth/agent-universe@2.7.0`，点「运行市场端到端演示」可见结算链路。

## 本版无运行时逻辑变更

v2.6.0–v2.6.9 连续十个版本完成了账本整数化、托管防铸币、认证式 BFT-lite、重放保护、状态机恢复边、证据闸门、持久化往返、MCP schema 校验、合约可部署性、CI 真实性、版本一致性、MCP Bearer 认证、LLM 去 panic 与文档诚实标注。v2.7.0 是这些修复成果的**客户端分发节点**，不再叠加新的运行时特性。

- `node js/test/test.js`：20 项通过。
- `node test/regression.js`：14 通过。
