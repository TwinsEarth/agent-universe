# v3.9.6 — 比特币/以太坊 Agent 经济体（7/9）：BTC HTLC 纯链下确定性校验 + RGB 客户端验证承诺位置校验（P2WSH 脚本结构解析 + SHA256 hashlock / CLTV 超时 / 整数 sats 守恒 + witness program 比对 + opret-first / tapret-first 承诺锚点定位；只做链下结构自洽校验，不连 BTC 节点、不广播、不持私钥、不签 HTLC、不真转资产、不解真实区块、不做完整 Script 解释器、不做 RGB 状态转换与 tapret tweak 推导，生产 finalize 默认 HTLC_NODE_NOT_CONFIGURED fail-closed）

## 一、交付了什么

v3.9.0 立「只决策不动钱」的结算路由，v3.9.1 立「签名是宿主能力」的边界，v3.9.2 落地
EVM x402，v3.9.3 落地闪电 L402，v3.9.4 落地 ERC-8004，v3.9.5 落地 ERC-4337 Paymaster。
v3.9.6 把 **比特币侧在上沙盒可以安全做的纯链下校验部分**落地：在不连任何比特币节点、
不持任何私钥、不读真实区块的前提下，对一笔哈希时间锁合约（HTLC）的 witness 脚本做
确定性结构解析，校验 SHA256 哈希锁、CLTV 时间锁单位与超时边际、整数聪金额守恒、
P2WSH witness program 是否匹配；并对 RGB 客户端验证协议里的承诺锚点（opret-first /
tapret-first）做输出脚本位置与形状的纯校验。真实的 HTLC 打包/上链/结算、RGB 状态转换与
tapret tweak 密码学推导由宿主在后续版本经独立闸门授权，本版本一律 fail-closed 或诚实标注
未实现，不伪造真网可用。

本版本**不引入任何新 crate**（仅复用仓内已有的 `sha2 0.10` / `hex 0.4` 及 std 的
`serde`，PaymentHash/Preimage 直接复用 `l402` 既有类型，不重复定义）；零浮点、零
syscall、零 unsafe、无 IO、无生产 panic；不连 RPC/节点、不构造可广播交易、不持私钥、
不签 HTLC、不真转资产、不解析真实区块、不实现完整 Bitcoin Script 解释器、不做 RGB 状态
转换验证与 tapret tweak 推导。

新增文件 `gsn-core/src/economy/payment/htlc.rs` 与
`gsn-core/src/economy/payment/rgb.rs`，并扩展 `payment/mod.rs` 与
`plugin/system/mod.rs`。不改 router.rs（3.9.0）、signer.rs（3.9.1）、x402.rs（3.9.2）、
l402.rs（3.9.3）、erc8004.rs（3.9.4）、paymaster.rs（3.9.5），与它们并列、互不改动。

1. **HTLC witness 脚本确定性解析 `parse_htlc_script`**：识别标准模板
   `OP_IF OP_HASH256 <32 hash> OP_EQUALVERIFY OP_DROP <33 recv> OP_CHECKSIG OP_ELSE
   <locktime> OP_CHECKLOCKTIMEVERIFY OP_DROP <33 send> OP_CHECKSIG OP_ENDIF`，逐字节
   校验操作码/直接推送长度/32 字节哈希/33 字节公钥，任何结构偏差具名
   `HTLC_MALFORMED_SCRIPT`，坏 hex `HTLC_BAD_SCRIPT_HEX`。
   - CLTV 锁定期推送按**最小小端编码**解析：长度 1..=4 字节小端累加；多字节时最高有效
     字节（数组末字节）为 0 判非最小 `HTLC_LOCKTIME_NON_CANONICAL`（低位字节为 0 合法，
     256=[0x00,0x01]）；末字节 bit7 置位（脚本数为负）拒绝；值为 0
     `HTLC_INVALID_LOCKTIME`。时间单位以 500_000_000 为界：< 为区块高度，
     >= 为 Unix 秒（与 Bitcoin Core nLockTime 口径一致）。
   - `p2wsh_program(script) = SHA256(script)`（BIP141 witnessProgram，单 SHA256），
     供与调用方声明的 witness program 逐字节比对。

2. **哈希锁 / 金额守恒 / 超时三道确定性校验**：
   - `verify_hashlock`：标准 `SHA256(preimage) == payment_hash`（复用 l402 的
     PaymentHash/Preimage），不符 `HTLC_PREIMAGE_HASH_MISMATCH`。
   - `verify_amount_conservation`：`offered + fee == total`，u64 checked_add 防溢出，
     offered/total 必须为正，任何不守恒具名 `HTLC_SETTLEMENT_MISMATCH`。
   - `verify_timeout`：`current >= locktime` 判 `EXPIRED`；剩余时间小于调用方给定
     `min_remaining` 判 `MARGIN_TOO_SMALL`；current/min_remaining 由调用方显式传入，
     内核不读系统时钟。

3. **`HtlcOffer::validate` 与收据 `HtlcReceipt`**：一次校验脚本结构、脚本内 32 字节哈希
   与声明 payment_hash 一致、preimage 哈希、witness program 匹配、金额守恒、超时边际。
   收据回显 payment_hash / receiver / sender pubkey hex、locktime、locktime_units
   （实测小写 `block_height`/`unix_seconds`）、offered/fee/total sats（u64）、
   `witness_program_matches`，且恒 `onchain_packed_or_confirmed=false`。
   **诚实边界**：脚本模板用 OP_HASH256（双 SHA256）锁原像，而凭证侧 hashlock 用标准单
   SHA256(preimage)；本版只保证「脚本内 32B 与声明 payment_hash 一致」与
   「SHA256(preimage)==payment_hash」两条结构自洽，不实现完整 Script 解释器去强制统一
   OP_HASH256 的双哈希语义，已在状态 note 明确登记。

4. **生产结算 fail-closed `finalize_htlc`**：本版本无比特币节点后端，对任何结算请求一律
   `HTLC_NODE_NOT_CONFIGURED` 具名拒绝，不构造、不签名、不广播赎回交易，也不产出原像，
   绝不伪造真网结算。真实节点后端留待宿主经独立闸门注入。

5. **RGB 承诺位置纯校验 `rgb.rs`**：
   - `CommitmentScheme` 实现 `std::str::FromStr`（接受 opret_first/opret 与
     tapret_first/tapret），`as_str` 回规范名。
   - `verify_opret_commitment`：在输出中定位唯一一个精确 `OP_RETURN(0x6a)
     OP_PUSH_32(0x20) <32 commitment>` 输出并回其索引；裸 OP_RETURN 放行；携带非 32 字节
     /非规范推送具名 `RGB_OPRET_MALFORMED_OUTPUT`；两个相同锚点判 malformed（锚点唯一）；
     找不到 `RGB_OPRET_COMMITMENT_NOT_FOUND`。
   - `verify_tapret_placement`：目标输出须为 segwit v1 Taproot 程序
     `OP_1(0x51) OP_PUSH_32(0x20) <32>`，且必须是第一个 Taproot 输出，索引越界具名
     `RGB_TAPRET_OUTPUT_INDEX_OUT_OF_RANGE`；`require_derivation=true` 一律
     `RGB_TAPRET_DERIVATION_NOT_IMPLEMENTED`，收据 `derivation_verified` 恒 false——本版
     不做承诺 tweak 密码学推导（需 RGB Core），显式不声称已验证。
   - `CommitmentClaim::verify` 按方案分派，回 `CommitmentReceipt`
     （verified/scheme/commitment_hex/anchor_output_index/derivation_verified/
     rgb_state_transition_validated=false）。
   - `RgbError` 全 `RGB_*` 前缀，impl Display/Error，生产全具名返回不 panic。

6. **PMB 字节桥**（同一 T0 系统插件 `com.twinsearth.sys.payment-router`）：新注册
   `btc_htlc_verify` / `btc_htlc_finalize` / `rgb_commitment_verify` 三个 handler，连旧
   v3.9.0–v3.9.5 共 **19 个 handler**。空负载/坏 JSON 一律运行时拒绝。`payment_router_status`
   增 `btc_htlc_introduced_in=v3.9.6` / `rgb_introduced_in=v3.9.6` 与完整诚实块
   （btc_node_connection=false、transaction_broadcast=false、
   full_bitcoin_script_interpreter=false、integer_sat_amount_conservation=true、
   htlc_finalize_fail_closed=true；rgb tapret_tweak_derivation=false、
   rgb_state_transition_validation=false、onchain_anchor_write=false），`enforceable` 增
   htlc_fail_closed_when_node_unconfigured /
   rgb_tapret_derivation_honestly_not_claimed 两位，`provided` 增 btc_htlc_verify /
   rgb_commitment_verify 两 true 与 btc_node_connection=false；`capabilities_declared`
   由 6 增至 8（加 `btc:htlc:read`、`rgb:commitment:read`），链上写/节点/tweak 推导登记为
   后续保留能力。

内核仍零浮点、零 syscall、零 unsafe、无生产 panic、无 IO；不连 BTC 节点、不广播、不持
私钥、不签 HTLC、不真转资产、不解真实区块、不做完整 Script 解释器、不做 RGB 状态转换与
tapret tweak 推导。

## 三、诚实边界（做不到的具名拒绝）

- 本版本交付的是 **BTC HTLC / RGB 的纯链下确定性校验内核（结构解析 / 哈希锁 / 时间锁 /
  整数守恒 / 承诺位置）**，不是比特币节点集成，也不连任何 RPC/P2P 网络：不打包、不签名、
  不广播赎回交易，不读 mempool/UTXO/真实区块，不查链上确认数，不产出原像，不真转任何
  资产。`verified=true` 只表示按调用方提供的脚本/哈希/金额/时间快照结构自洽，不代表链上
  已打包或会成交。
- **不做完整 Bitcoin Script 解释器**：只识别固定 HTLC 模板的字节结构，不实现脚本栈求值；
  脚本里的 OP_HASH256（双 SHA256）与凭证侧单 SHA256(preimage) 的语义统一不在本内核强制，
  仅保证两处 32 字节与声明 payment_hash 一致。任意非模板脚本一律 HTLC_MALFORMED_SCRIPT。
- **CLTV 仅按 nLockTime 口径解析与判定**（500_000_000 分界、最小正整数小端、无符号
  <2^31）；不做交易级 sequence/CSV 交互、不校验脚本 witness 具体满足路径。
- **金额守恒为整数 sats 复算**（offered+fee==total，u64 checked），不含手续费市场动态、
  粉尘限制、mempool 策略或真实费率。
- **RGB 不做状态转换验证与 tapret tweak 推导**：opret 只定位 OP_RETURN 承诺位置，tapret
  只校验输出形状/首个 Taproot/索引；`require_derivation=true` 一律
  RGB_TAPRET_DERIVATION_NOT_IMPLEMENTED，derivation_verified 恒 false，不锚定真实 RGB
  合约、不验客户端验证密封封包。
- **finalize 默认 fail-closed**：无节点后端时 btc_htlc_finalize 一律
  HTLC_NODE_NOT_CONFIGURED；时间 current、witness program、金额、输出脚本均由调用方显式
  取证传入，内核不读时钟、不联网，保持纯函数可复算。
- 链上锚定/跨链桥风控 fail-closed 在 **v3.9.7**；ZK 支付意图 / OWS 统一钱包 / 合规接口在
  **v3.9.8**。在对应版本落地前这些方法不注册（NotFound）或只提供校验/决策面，不伪造真网
  可用。
- 文档涉及的外部协议/生态数字（RGB/Taproot 采用、闪电网络规模、比特币安全预算等）均为
  **第三方报道口径，非本仓复测**，内核不内置这些数字作为事实。
